# Anvil roadmap

Anvil is a browser-based parametric solid modeler with a SolidWorks-style workspace and a scripting API that Claude can drive. Phases are ordered; each session picks up the first unchecked items.

## Phase 1 — foundation (session 1, 2026-09-21)
- [x] BSP CSG kernel (union / subtract / intersect / transform / signed volume)
- [x] Sketch entities: line, corner & center rectangle, circle, polygon, straight slot, centerpoint arc, polyline, point
- [x] Profiles: loop chaining, nesting (holes), ear-clipping triangulation
- [x] Features: extrude (blind / through all / mid-plane / two directions, boss or cut), revolve (axis = sketch X/Y or a line), linear pattern, circular pattern, mirror (feature or body), reference plane
- [x] Rebuild pipeline with per-feature errors and warnings
- [x] Mesh with coplanar face grouping, face outlines (T-junction aware), mass properties
- [x] Exports: STL, DXF of a sketch, DXF of a planar face (OUTLINE / HOLES layers)
- [x] Script builder API + generate-script-from-model round trip
- [x] SolidWorks-layout UI: menu bar, CommandManager ribbon (Features / Sketch / Evaluate / Sheet Metal), FeatureManager tree, PropertyManager, heads-up view toolbar, Task Pane, status bar, triad
- [x] Viewport: orthographic orbit / pan / zoom-at-cursor, standard views, normal-to, previous view, zoom to area, display styles, section view, face hover + selection highlight, B-rep style edges with tangent edges hidden
- [x] Sketch mode: grid + snapping, all tools drawn by clicking, entity edit by typing values, undo
- [x] Feature editing (double-click), rename, delete with dependents, undo/redo
- [x] Hole Wizard (simple hole on a picked face), base flange (thin extrude recording sheet params)
- [x] Persistence: autosave, named saves in localStorage, JSON open/save, script open
- [x] `window.anvil` automation API

## Phase 2 — modeling depth
- [x] Edge selection: kernel `bodyEdges` (faces, interior directions, convexity, tangent-chain propagation), viewport edge picking with occlusion test, hover/selection highlight
- [x] Fillet and chamfer on selected edges: swept cross-section per edge, mitred caps at shared vertices, convex edges cut / concave edges add; `p.chamfer(d, [[x,y,z]])`, `p.fillet(r, [...])`
- [x] Shell (`p.shell(t, [[x,y,z]…])`: inner solid = body minus a T-deep slab behind every kept face, each slab outline grown by T·tan(φ/2) per edge so slabs meet at exact offset corners; removed faces get an extension out through the face; body − inner. Faces picked by point, Shell PM with cavity preview)
- [x] Sketch on a picked face keeps the face's edges available: Convert Entities (face outline stored on the sketch as `faceLoops`)
- [x] Offset Entities (mitred polygon offset, inward/outward, construction option) and Sketch Fillet (click a corner of a rect/polygon/polyline)
- [x] Trim (`trimEntity`: exact seg/arc intersections, removes the span between neighbours, circles become arcs, slots explode, rects become polylines), Mirror Entities (`mirrorEntities(axis)`: sketch axes or a line, arcs/polygons stay true), Linear Sketch Pattern (`patternEntities`); PMs with live temp previews
- [x] Smart Dimension: click an entity, then place the dimension (aligned / horizontal / vertical for lines, rectangle edges, Ø, R, slot length and width); placed dimensions live on the sketch (`dims`), draw with extension lines and arrows in an SVG overlay, round-trip through `SketchBuilder.dim`, and the value box drives the entity through `Kernel.setDimValue`; View ▸ Sketch Dimensions also shows driven values for undimensioned entities
- [x] Sweep along a polyline or line/arc path sketch (mitred sections, profile auto-oriented) and loft through 2+ sketches (resampled outlines, rotation-matched); `p.sweep({profile, path})`, `p.loft([ids])`, Swept/Lofted Boss and Cut PMs
- [x] Draft on extrudes: `extrude(d, { draft: deg, draftOutward })`, tapered prism with mitred section offsets (holes widen as material narrows), Draft group in the Boss/Cut-Extrude PM; collapse detected with a clear error
- [x] Edge selection + "Normal To" on edges (view along the mean face normal with the edge horizontal); Measure shows edge length, endpoints, direction and the angle between its faces

## Phase 3 — sheet metal (the user's shop workflow)
- [x] Edge flange: pick straight edges of the flat sheet, bend radius + angle + length, reverse side; "Bend Outside" placement; `p.sheet(T,R,K)`, `p.baseFlange(T)`, `p.flange(L, [[x,y,z]], {angle, reverse, radius})`
- [x] Flatten: base face outline + unfolded flanges (bend allowance = angle × (R + K·T), K = 0.71 steel / 0.64 aluminum), flat-pattern viewer with bend centre lines and UP/DOWN labels
- [x] Flat pattern DXF with OUTLINE / HOLES / BEND / NOTES layers (blank note carries T, R, K)
- [x] Sheet metal parameters in Custom Properties (thickness, bend radius, K-factor)
- [x] Flange placement options: Material Inside / Material Outside (`position` option: the flange section shifts by R+T or R and the base is trimmed by the same strip)
- [x] Flanges on flanges (flat pattern unfolds recursively: each wall face is mapped rigidly into the flat and its own flanges follow)
- [x] Holes on flange walls carried into the flat pattern (wall faces contribute their real outlines; regions are merged with the CSG kernel and the top-face outline is the blank)
- [x] Hem (`p.hem(L, edges, {gap})`: a 180° flange with R = gap/2, unfolds with BA = π(R + K·T)) and Jog (`p.jog(height, length, edges, {angle, reverse})`: two opposite bends in one feature, wall length solved so the flats sit `height` apart, unfolded as UP + DOWN); flanges accept `toward: [x,y,z]` to pick the fold side by direction
- [x] Miter flange (`p.flange(L, edges, { miter: true, miterGap })`: flanges on adjacent edges are swept past the shared corner and clipped by the bisector plane, gap split evenly; Miter Flange ribbon button + Miter group in the Edge-Flange PM)
- [x] Auto relief at flange ends (`relief: 'rect' | 'obround'`, `reliefWidth` default T, `reliefDepth` default T/2: where the plate continues past a flange end a slot is cut from the base before the bend is added; no relief at convex corners or mitred ends)
- [x] Bend strips of mitred flanges extended to the mitre line in the flat pattern (flange info carries `miterPlanes`; each strip end is a trapezoid ending on the mitre line, bend lines reach it, no step in the blank)
- [x] Thickness-aware "normal cut" (`p.cut(d, { normalCut: true })`, Cut-Extrude PM ▸ Sheet Metal ▸ Normal cut, default on for sheet parts: the part of the tool inside the body is meshed, its sheet-surface faces (entry side when the cut has a direction) are pushed straight through the thickness and replace the tool, so cuts from tilted sketches leave walls square to the sheet)

## Phase 4 — robustness and performance
- [x] Faster CSG: bounding-box early-out per polygon (2026-09-22T20: far polygons skip the BSP clipping, disjoint operands short-circuit; bench sum of medians 2994 → 2375 ms, hole patterns and grooves 1.5–2×); 2026-09-25T15: faces a boolean did not cut are restored whole (`CSG.options.restoreWhole`), so polygons stay split only where material was removed; Funnel 1844 → 1292 ms and 14071 → 4576 faces. cloud-2026-09-25b: BSP trees built from the near region only (`CSG.options.nearTrees`): an operand whose polygons are mostly far from the other one is closed off by a box around the near region, the box-face caps classified by ray casts; bench sum of medians 1510 → 1050 ms, Rounded handle 5.4×, Mug 2.7×, every example volume unchanged to 1e-9 (done earlier: balanced-tree unions for shell slabs and sweep segments, 7–10× faster than a running union)
- [x] Cache tool bodies between rebuilds when a feature did not change: `Kernel.rebuild(model, cache)` restores the longest unchanged feature prefix (per-feature keys = feature JSON + sheet params; bodies are immutable so snapshots are references) and rebuilds only from the first changed feature; the UI keeps `App.buildCache`
- [x] Web Worker rebuilds so the UI never freezes (`worker.js` owns `Kernel.rebuild` and its cache, `UI.rebuild` returns a Promise with coalescing and a synchronous fallback, Edit ▸ "Rebuild in background (Web Worker)" toggle, `CSG.pack/unpack`, `Kernel.packBuild/unpackBuild`)
- [x] Degenerate geometry guards: zero-area loops dropped with a "zero-area contour" warning, self-intersecting loops error with "crosses itself near (x, y)" from extrude/revolve/sweep/loft, NaN depths/angles/path points error with "must be a number"
- [x] Mesh quality (cloud-2026-09-25g): `Kernel.meshQuality` (welded open / non-manifold edges with T-junctions resolved, collinear slivers, needles, min angle) asserted closed, manifold and sliver-free on every Design Library example; lofts between convex parallel sections are the convex hull of the sections (planar side faces), which removed the Funnel's shell grooves, its 1e-5 mm crack at the tube and the extra lines in its drawing (Funnel 762 → 276 ms)
- [ ] A test page (parallel session owns `tests/kernel-tests.html`) run before every session ends

## Phase 5 — assemblies and drawings

- [x] Simple assembly document: insert parts, mate by coincident planes / concentric axes (cloud-2026-09-25c: `anvil/assembly.js` — assembly model `{ type: 'assembly', components, mates }` with Design Library / script / embedded part sources, Coincident and Concentric mates on faces, cylindrical faces, planes and axes, greedy + Levenberg–Marquardt solver with per-component DOF and conflict errors, faceted cylinder axis fit, `a.insert/a.mate` script round trip, mass properties across components; File ▸ New ▸ New assembly, Assembly ribbon tab, Insert Components and Mate PropertyManagers, component rows `(f)`/`(-)` and a Mates folder, `anvil.insert/mate/components/mates`, Pinned plate assembly example)
- [x] Assembly follow-ups: Distance / Angle mates, offsets, Move / Rotate Component, Interference Detection (cloud-2026-09-25e: `distance` / `angle` mate types and Coincident `offset` with *Flip dimension* in the solver (signed plane gap targets; a signed angle about a canonical angle axis, the hinge axis when earlier mates leave one) and in the Mate PropertyManager (value boxes that start at the measured distance / angle); `a.distance` / `a.angle` script round trip; `Assembly.moveComponent / rotateComponent` + a viewport drag of floating components that re-solves the mates live and on drop, Move / Rotate Component PM with By Delta XYZ; `Assembly.interference` (pairwise `CSG.intersect` volumes) with an Interference Detection PM on the Evaluate tab highlighting the pairs and drawing the common volumes, `anvil.interference()`; fully defined components show no prefix; Distance and angle mates / Interference check examples)
- [x] 2D drawing view: orthographic projections with hidden lines as SVG, dimensions, export PDF/DXF (cloud-2026-09-25d: `drawing.js`: File ▸ Make Drawing from Part, Drawing ribbon tab (Standard 3 View, Model View, Smart Dimension, Model Items, Sheet Properties, Save as SVG / DXF / PDF), drawing FeatureManager with sheet and view rows; Front / Top / Right third- or first-angle plus Isometric, exact hidden-line removal against the mesh with silhouettes of faceted curved faces, sheet with title block and automatic scale, overall and diameter model dimensions, DXF one layer per view, PDF 1.4)
- [x] Drawing views: Projected, Section and Detail views; dimensions that follow the part (cloud-2026-09-25f: `drawing.js` — Projected View up / down / left / right of any view, aligned and sliding along the projection; Section View from a horizontal or vertical cutting line, the part cut exactly by CSG with one cap face per body, ANSI31 hatch, chain cutting line with arrows and letters, SECTION A-A; Detail View circle with its own scale (2x the parent), clipped lines and arcs, DETAIL B / SCALE 4:1; user Smart Dimensions reattach to the same edge or circle after a rebuild or are flagged dangling in olive; SVG / DXF (PHANTOM, ARC) / PDF of all of it)
- [x] Drawings of assemblies (cloud-2026-09-25h: `drawing.js` — File ▸ Make Drawing from Assembly; Standard 3 View, Model, Projected, Section and Detail views of the solved components with hidden lines across all of them (edges kept per component, a hidden edge under another component's visible one dropped); Section View hatches every component at its own angle (45°, 135°, 30°, 120°, 60°, 150°, then 1.6× wider); Bill of Materials (ITEM NO., PART NUMBER, DESCRIPTION, QTY.; identical components — same source — on one row) anchored to a corner of the sheet or dragged, kept clear by Standard 3 View; Auto Balloon (one per item or per instance) numbered from the BOM at every render; BOM / BALLOONS layers in SVG / DXF / PDF; `anvil.drawing.autoBalloon / bom / deleteBalloons`)
