## Files — one line each: what the file owns
- `ui-sketch.js` — sketch mode (enter / exit / cancel), mouse + keys in the viewport, `setTool` / `cancelTool`, inference (`inferPoint`, snaps, tangent lock), `placePoint` / `addEntity` (every drawing tool commits here), on-screen numeric box + `UI.sketchUnitBox`, Quick Snaps, Rapid Sketch, sketch dimension drawing + Modify box, sketch undo-gesture rule, `UI.sketchPreview`.
- `ui-sketch-lines.js` — Line / Centerline / Midpoint / Parallel Line, the five Rectangle types, Point: tool PMs (`UI.sketchToolPMs.line`, `.point`, rect types) and entity PMs (Line / Point Properties, `driveLine`).
- `ui-sketch-curves.js` — Circle / Perimeter Circle, Arcs (Centerpoint, Tangent, 3 Point), Polygon, the four Slots: tool + entity PMs, `UI.sketchCurveOptions`.
- `ui-sketch-tools.js` — Sketch Fillet / Chamfer (`cornerTool`), Offset, Trim / Extend, Convert Entities, Intersection Curve, Move / Copy / Rotate / Scale / Stretch (`transformTool`), Linear / Circular Sketch Pattern, Dynamic Mirror, Modify Sketch, Segment, Equation Curve, Jog Line, Close Arc.
- `ui-sketch-dims.js` — Smart Dimension extras + Dimension PM, Add / Display-Delete Relations PMs, Fully Define Sketch, ordinate / chamfer / path-length / angular-running dims, Instant2D (second IIFE at the end).
- `ui-sketch-construct.js` — Tangent / Perpendicular Line, Bisector, Tangent Circle, Split / Join Entities; rfGS: Create Sketch from Selections (`UI.cmdSketchFromSelections`), Derived Sketch (`UI.cmdDerivedSketch(parentId?, target?)`, `UI.cmdUnderiveSketch(id?)`), the `UI.rebuild` wrapper that runs `K.syncDerivedSketches`, and the Intersection Curve wrapper for a selected plane with no sketch open (the tool itself is in `ui-sketch-tools.js`). A derived sketch is an ordinary sketch with `derived: { from, dx, dy, at, name }`: the entities are copies, each sync takes the shape from the parent and keeps how far the copy was dragged (`at` = each entity's anchor after the last sync). Script line: `.derivedFrom("Sketch1", dx, dy)`. A deleted parent leaves the copy as it stands.
- `ui-sketch-spline.js` — Spline, Style Spline, Ellipse, Partial Ellipse (via `UI.sketchFreeHooks`), curvature comb, their PMs.
- `ui-sketch-text.js` — Sketch Text (tool PM, entity PM, text along a curve). `sketch-font.js` is the stroke font (no DOM). Text on a spline: `pathGeomOf` (Kernel.textPathOf) copies the whole handle `tans[i]` incl. curvature control `[3]` and a conic `conic` rho (lane sketchgaps; tests rfJH).
- `ui-sketch-blocks.js` — Blocks (Make / Edit / Insert / Add/Remove / Rebuild / Explode / Save); engine is `Kernel.makeBlock …` in kernel-sketch.js (`blockAddRemove(f, id, add, remove)` = redefineBlock with the removed pieces' `blk` cleared first; `rebuildBlocks(f)` re-places instances off their definition). Add/Remove PM: clicks go to `onEntityPick` (loose entity → add, own piece → remove); in Edit Block it finishes the edit, applies, re-opens it.
- `ui-sketch-import.js` — Insert DXF / File ▸ Open .dxf, Check Sketch for Feature, Repair Sketch (engine `dxf-import.js`: `DxfImport.parse / check / repair`, and `DxfImport.prepare` = the whole import PM pipeline: layers, units, position, Merge points closer than, then with Repair a second pass closing gaps up to `gap` (0.001 in / 0.025 mm) — the PM's build() only calls it; `repair` widens tol by 1e-6 relative so a gap of exactly tol closes). Tests rfJL (kernel: customer flats as DXF text, mm into inch, Base Flange volume; smoke: the PM by clicks). **DWG** (lane dwgin, rfKW): no DWG reader in the page; a .dwg is POSTed to `api/dwg2dxf` (`UI.dwgToDxf` → `UI.openDWGFile` / `UI.importDWGData` → the DXF path above). Served by `serve.ps1` (`Convert-DwgToDxf`), the desktop app (`desktop/converters.js` `dwg2dxf`, app://anvil/api/dwg2dxf) and the runner (`anvil.js dxf2sketch x.dwg` → `headless/dwg.js toDxf`); each runs the ODA File Converter (ACAD2018 DXF) if installed, else LibreDWG `vendor/libredwg/dwg2dxf.exe` (`$ANVIL_LIBREDWG`), no `--as` (the DXF keeps the DWG's version; LibreDWG's `--as r2018` up-conversion writes an empty ENTITIES). No converter: 503 → toast naming get-libredwg.ps1; no server / static host / file:// → "DWG needs the local Anvil server…"; not `AC…` bytes → refused before any request. LibreDWG's *writer* (dxf2dwg) is lossy (needs full tables, R2004 out empty, drops bulges / fit points / weights / a mirrored INSERT's Y scale): never use it to make test DWGs from hand-written DXF; build them with ezdxf first, and keep converter OUTPUT as fixtures (tests/kernel/rfKW.js).
- `ui-sketch-layers.js` — sketch layers, shaded regions + open-end marks, Copy / Paste of entities. `ui-levels.js` (transform-view card) maps layers to part-wide levels.
- `ui-sketch-picture.js` — Sketch Picture (`sketch.pictures`).
- `ui-relations.js` — two-entity distance / angle Smart Dimensions, relation highlight, dragging an under-defined sketch, "Make Dimension Driven?" modal, `markDirty`.
- `ui-select.js` — `BoxSelect` (no DOM) + selection list (`UI.selection`, `UI.setSelection`), Select-tool click (`UI.sketchSelectClick`), Selection Filter (F5), box select, Instant3D handles. Lane CO: a command with `regionsActive()` true routes hover (`pickHover`) and clicks (`selectClick`) to its `pickRegions(mx, my)` → `{ kind: 'region', sketch, index, p, region, plane }` and nothing else; `drawSelectionExtras` fills `cmd.pickedRegions()` (yellow) and the hovered region / listed row (orange) with `regionMesh` (`THREE.ShapeUtils.triangulateShape`, holes kept).
- Selected Contours (lane CO, `contourPicker` in ui-commands.js, used by `cmdExtrude` / `cmdRevolve`): the box is the last PM group, starts active when `Kernel.regionsAmbiguous(sketch)`, lists picks as `Sketch1-Region<n>` (n = `Kernel.regionAt(...).index + 1`), toggles a region per click, previews through the PM's `preview(v)`; the feature stores `contours: [[u, v]]` (`region.p`), none = the whole sketch. Tests `rfCO` (smoke: real mouse events through `selEv` / `selClick`, screen points from `UI.worldToScreen(K.to3D(plane, u, v))`).
- `sketch-solver.js` — `SketchSolver` (no DOM): refs, relations, LM solver, analyze / DOF, infer, drag, and all 2D editing maths (fillet, chamfer, offset, trim, extend, patterns, transforms, constrainAll, ordinate sets, contourOffset). Tail IIFEs add rfAU blocks, rfAQ dims, script hooks.
- `kernel-sketch.js` (read-only for this lane: kernel lane owns it) — `Kernel.entityPolylines`, `entityCurves`, `sketchProfile` / `checkProfile`, `dimGeometry` / `dimValue` / `setDimValue`, `mirrorEntity`, `trimEntity`, `splineGeom`, `ellipsePoint`, text layout, blocks, `LAYER_PRESETS`, tessellation (`segsForRadius`).
- `ui-core.js` (shared) — `UI.App` state, `pushUndo` / `undo` / `redo`, `updateSketches`, `updateTemp`, `screenToPlane` / `worldToScreen`, `activeSketchFeature`, `activePlane`, `pickEntity`. `ui-commands.js` (shared) — `UI.openPM` / `pmEnter` / `pmOK`, `UI.sketchEntityPMs` dispatch, `deleteSketchEntity`.

## How things are done here
- **Dimension precision (rfIF)**: the Dimension PM's Tolerance/Precision lists are `select` fields with `icon:` (`dimTolType`, `dimPrecision`; ui-commands.js draws a 16 px icon label, `f.label` becomes the tooltip / aria-label, row class `.pm-row-ico`; tests find them by `#pm select[data-key="tolType" | "prec"]`, not `pmField`). Precision list `precOptions(docPlaces)`: `0` None … `8` .12345678, then `auto` "<doc> (Document)" last. The document's precision is `model.dimPrecision = { linear?, angular? }` (absent = inch .123 / mm .12 / angles .12; the default is never stored): `UI.docDimPrec(angle)`, `UI.dimPlaces(d, angle)`, `UI.setDocDimPrecision({ linear, angular })` (undo step, redraws), task pane Document properties > Dimensions; `fmtVal` keeps the old text while the document is at its default. Script `p.dimPrecision({ linear: 4 })` (Builder method and the generateScript line in kernel-script.js; kernel group rfIF). The Modify box rounds to max(4, places).
- **Tool PM**: register `UI.sketchToolPMs[tool] = function (tool) { UI.openPM({...}) }` (imitate `UI.sketchToolPMs.line` → `openInsertLine` in ui-sketch-lines.js). Spec fields: `title`, `icon`, `sketchTool: '<tool>'` (marks it the tool's own PM: closes when the tool is put down), `noFocus`, `keepSelection`, `values`, `groups: [{ title, show(v), fields: [{ type: 'number'|'radio'|'check'|'select'|'text'|'html'|'buttons'|'pick'|'static', key, label, unit: 'u' (doc length) | '°', min, step, options: [[v, label]], rerender, show(v) }] }]`, `onChange(values, key)`, `onOK(values)` (return `false` refuses; `{ keepOpen, promise }` stays open), `onCancel`, `onClose`, `message` (goes to the sketch hint + status), `onSelection`, `onEntityPick`, `exprMap`, `help`. Selected-entity PMs: `UI.sketchEntityPMs[t] = function (index, entity, f)`.
- **Extra drawing-tool behaviour** without touching ui-sketch.js: `UI.sketchToolDefs[tool]` (steps, entities, accept, after, fields, live, typed, readout), `UI.sketchToolHooks[tool]`, `UI.sketchFreeHooks[tool]` (click-driven tools: spline, ellipse), `UI.sketchCommitHooks.push(fn(f, n0, st))` (runs after any tool commits; Dynamic Mirror uses it), `UI.sketchExitHooks`. Doc comments sit above each registry in ui-sketch.js.
- **Command PM (non-tool)**: `cmdX()` → `sketch()` guard (toasts "Open a sketch first.") → `selIdx(f)` (selected entity indices) → `UI.openPM`. Imitate `UI.cmdOffsetEntities` or `UI.cmdCloseArc` (ui-sketch-tools.js).
- **A new relation type** (rfCR, Equal Curve Length `equalcurve`): everything is data-driven in sketch-solver.js — add it to `TYPES` (name + glyph: what Display / Delete Relations and `describe` show), `ADD_ORDER` (the Add Relations button order), `match` (which ref kinds: `point` / `line` / `circle` / `free`), a `relEquation` case (`n` equations, `f(E)` residuals; return null for entity types it cannot take, which `addRelation` turns into "does not apply"), and a line in `applicable` when `match` alone over-offers. No UI file changes: the Add Relations PM (`sketchRelationGroups`, ui-sketch-dims.js) and the lists read the catalogue. `.rel('equalcurve', [a, b])` works in scripts at once. Tests: rfCR (kernel + smoke).
- **Replace Entity** (rfCR, `UI.cmdReplaceEntity`, ui-sketch-tools.js): two `pick` boxes filled by `command.onSketchPoint` clicks (`UI.pickEntity`), a preselected entity is the one to replace, ✓ runs `step(() => S.replaceEntity(f, i, j, { construction }), true)`. The engine (`SketchSolver.replaceEntity`) maps every ref of i (`mapRef`: whole → j, end / corner → j's nearest end or corner, centre / midpoint → the same of j, else the relation drops), moves placed dimensions j can carry (`K.dimGeometry`) and re-applies their values with `setDim`, deletes i (`removeEntity` + splice + dims shift) or marks it construction, then `clean` / `solve`; more conflicts *or* more redundancy than before restores the snapshot (`tSave` / `tRestore`). The sketch right-click row: `sketchMenu` (ui-sketch.js) builds the full list with `UI.sketchMenuItems(items)` and splices the row after Mirror Entities… (a built list, `items.sketchMenu`, is shown by showMenu as it is). Tools ▸ Sketch Tools ▸ Replace Entity… is a one-off row in ui-panels.js `partMenus` (commands lane): `{ label: 'Sketch Tools ▸ Replace Entity…', icon: 'moveEnt', action: function () { UI.cmdReplaceEntity(); }, disabled: App.mode !== 'sketch' || !UI.cmdReplaceEntity }`.
- **One undo step**: `if (!App.sketchDirty) { UI.pushUndo(); App.sketchDirty = true; }` before editing (`addEntity`, `markDirty` in ui-relations.js). The flag is cleared on every mousedown / non-field keydown (ui-sketch.js tail), so one click / key = one step. For a command use `step(fn, always)` in ui-sketch-tools.js: fn returns `{ ok, error }`; a failure pops the undo snapshot. Solver tools are all-or-nothing.
- **Two-Enter rule**: `UI.pmEnter(inp, commit)` (ui-commands.js) — Enter in a box whose text changed commits it and keeps the PM ("press Enter again to finish"); Enter with nothing pending = ✓ and closes (`pmOK({ close: true })`). `commit(inp)` returning `false` refuses. Don't add your own Enter handlers in PMs.
- **One-Esc rule** (lane CG): every Esc of a command calls `UI.escapeCommand()` (ui-commands.js): the numeric / unit box and the Modify box close unapplied (ui-sketch.js `UI.escapeBoxes` hook; Parallel Line's unit box gets no `onFinish`), the tool goes down (`cancelTool`), the PM is cancelled (onCancel must put back what the command made: imitate `cornerTool`'s `restore(snap)`), so one press leaves nothing behind. A new box or sub-state: push a hook onto `UI.escapeBoxes` instead of handling Esc itself. Tests: `rfCG`.
- **Ending a Line chain** (rfCF, user 2026-10-14): a double-click ends the chain and discards the segment being pulled. `sketchClick` logs each Line-tool click on `App.toolState.clicks` (`{ sx, sy, made: [entity indices], pushed }`); the viewport `dblclick` handler takes back what the double-click's own two clicks made (the last two logged within 6 px of it: the segment to its point, a stub), with their relations (`SketchSolver.removeEntity`), dimensions and undo snapshots, then `finishChain()` (the tool stays). A deliberate click at the spot then a double-click on it keeps that segment (its two clicks made nothing); no chain in progress → `cancelTool()` puts the tool down. Tests that end a chain at a point therefore `rskClick(D); rskDbl(D)`; `rskDbl(D)` alone discards D.
- **Unit request box**: `UI.sketchUnitBox.open({ fields: [[label, key]], onChange(v), onCommit(v), onFinish(v) }, prefill)` / `.close()` / `.isOpen()` (ui-sketch.js; `UNIT_BOX_TOOLS` = circle, pcircle always ask). Values are parsed with shop input (`4-1/2`, `17/64`, `.25`). The drawing tools' own box: `openNumBox` / `numValues` / `typedPoint`.
- **Previews**: drawing tools set `App.tempEntities = [entities]` then `UI.updateTemp()`; commands draw orange dashed screen polylines with `UI.sketchPreview(polylines (sketch uv), style?, cls?)` and clear with `UI.sketchFeedbackClear()`; snap marks `UI.sketchSnapMark`. ui-sketch-tools.js uses PICK_STYLE (yellow dashed) / HOT_STYLE (orange).
- **Selection**: `UI.selection()` → list of `{ kind: 'entity'|'sketchPoint'|'sketchRef'|'dim'|'rel'|'face'|'edge'|…, index | ref }`; `App.sel` / `App.sel2` are the first two; `UI.setSelection(list)` sets all. A PM that should keep the selection needs `keepSelection: true` (closePM clears sketch selections otherwise).
- **Solver calls**: `SketchSolver.addRelation(f, type, refs, { value, off })` → `{ ok, rels, status, analysis }`; `solve(f, { dimTargets, relTargets, mob })`; `analyze(f)` → `{ dof, status: 'under'|'full'|'over', entities[], … }`; `setDim(f, i, v)` / `setRelValue` (refuse on conflict); `infer(f, i, { placed })`; `removeEntity(f, i)` (re-points rels + dims); `pointRefs(f, i)`. Refs: `"O"`, `"3"`, `"3.p1"`, `"3.p2"`, `"3.mid"`, `"3.c"`, `"3.v0"`, `"3.e0"` (ellipse `"3.v0"` axis ends, spline legs `"3.ek"`).
- **Dimensions**: Smart Dimension on one entity → `f.dims.push({ e, k, i?, off, ang? })`, value read from geometry (`Kernel.dimGeometry`), driven edit via `SketchSolver.setDim`; between two entities → a `distance` / `angle` rel with `v`, `dir: 'h'|'v'|'r'`, `tx`. Labels: `UI.dimLabelText`; length text via `SketchSolver.fmtLen` (".250 in").
- **Coordinates**: `UI.screenToPlane(mx, my, UI.activePlane())` → sketch `[u, v]`; back with `UI.worldToScreen(K.to3D(UI.activePlane(), u, v))`; px → sketch units `pxWorld` / `pxSize`. Tolerances are screen pixels (6–12 px), never mm.
- **Status / toast text**: `UI.setStatus('Mirrored 2 entities, 2 held Symmetric about Line1.')` for results and prompts; `UI.toast(msg)` for refusals / errors ("Radius too large … (at most R3.000 in)", "Select the entities to pattern first."). Full sentences with a period, SolidWorks names, values in document units; cancel says "<Command> cancelled.".

## Data shapes
Sketch feature: `{ id, type: 'sketch', name, plane: { ref: 'Front'|'Top'|'Right', offset } | { featureId } | frame, entities: [...], rels?: [...], dims?: [...], layers?, pictures?, blocks? }`.
Entity params (`SketchSolver` PARAMS): `line x1 y1 x2 y2`, `rect x y w h`, `crect cx cy w h`, `circle cx cy r`, `arc cx cy r a0 a1` (degrees, CCW), `slot x1 y1 x2 y2 w`, `aslot cx cy r a0 a1 w`, `poly cx cy r rot` (+`n`, `ins`), `point x y`, `ellipse cx cy rx ry rot`, `pellipse … a0 a1`, `polyline` / `spline pts: [[x, y]]`, `text x y` (+`path`). Flags: `construction`, `sharp` (virtual sharp point), `layer`, `infinite`.
Dim kinds `k`: line `len|dx|dy`; rect `w|h` (`i` = edge 0 bottom, 1 right, 2 top, 3 left); circle `dia`; arc / poly `r`; slot `len|olen|w`; polyline `seg` (`i`); ellipse `rx|ry`. `driven: true` = reference.
