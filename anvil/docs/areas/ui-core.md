# UI core (state, ribbon, PropertyManager, app shell, icons, styles) — agent map
Read this first; find line numbers with `grep -n <name> anvil/docs/INDEX.md`. Update this card at the end of any lane that touched this area (add what you had to dig for; fix what is wrong).

## Files — one line each: what the file owns
- `ui-core.js` — `var UI = (function () { … return { … } })()`: `App` state, three.js scene / camera / views (`VIEWS`, `setView`, `zoomToFit`), `mats` + `LINE_PALETTE` (all viewport colours), thick lines (`LINE_W`), highlights, planes / origin / sketch drawing (`updateSketches`, `sketchPointMat`), grid, picking, triad, View Selector, render loop, rebuild pipeline (`rebuild`, `applyBuild`, worker), equations input (`evalInput`, `parseLength`), Image Quality, undo / redo, dirty state + AutoRecover, `loadModel`. Its exports are the object literal at the end of the file.
- `ui-panels.js` — `(function (UI) { … })(UI)`: status line + toast, ribbon / CommandManager (`RIBBON`, `ASM_RIBBON`, `refreshRibbon`, flyouts, stacks, `extra` overflow to », View tab `viewTab`), FeatureManager tabs + tree (`refreshTree`, `featureIcon`), menus (`partMenus`, `MENUS`, `showMenu`, `renderMenuBar`), quick-access Undo / Redo (`syncStdToolbar`), Heads-up toolbar (`refreshHud`, `UI.HUD_ORDER`), modal (`showModal`, `confirmDialog`, `promptDialog`), Equations dialog, ConfigurationManager, tooltips (`setTip`, `ribbonTip`, `RIBBON_HELP`), Shortcut Bar (S).
- `ui-commands.js` — the PropertyManager renderer (`openPM`, `renderPM`, `renderField`, `pmOK`, `pmCancel`, `pmEnter`, pick lists, live previews `livePreview` / `UI.previewInWorker`, on-model handles) and every part feature command (`cmdExtrude`, `cmdShell`, `cmdEdgeFlange` …), `commitFeature`, `editFeature` / `editDispatch`, `deleteFeature`, DXF / DWG output (`UI.dwgConverter`, `UI.dxfToDwg`), assembly commands.
- `ui-app.js` — task pane (library, files, appearance, properties, script console), documents (`fileNew`, `newPart`, `newAssembly`), files & exports, mass properties, keyboard (`SHORTCUTS`, the document keydown handler, `undoCommand`), theme (`setTheme`), `window.anvil` automation API, Search Commands (`cmdSearchIndex`, `searchCommands`, `SEARCH_ALIASES`), `boot()`, AutoRecover offer.
- `ui-profiles.js` — interface profiles (`UI.Profiles`: SolidWorks / Mastercam layouts of the CommandManager, keys, mouse, dock, window frame), Tools ▸ Options ▸ Interface; see *Interface profiles* and *Window frame*.
- `icons-mastercam.js` — the Mastercam profile's icon set (rfLX), registered with `Icons.sets`; see *Look: icon sets (rfLX)*.
- `icons.js` — `IconsLib`; the global `Icons` is an accessor on window (rfGZ): `Icons(name, size, cls)` -> `<svg viewBox="0 0 16 16" data-wt="1">` weighed for that size and devicePixelRatio; `Icons.has`, `Icons.node` (cached clone), `Icons.svg(body, size, cls)` (any 16-grid body), `Icons.names()`, `Icons.raw(name)`, `Icons.strokeClass`. Drawing icons (DI in drawing-ui.js, SI in drawing-ui-sketch.js) wrap the global; the accessor weighs their output too.
- `style.css` — every chrome colour as a variable on `:root`, redefined under `:root[data-theme="dark"]`; sections by lane marker (`rfBF`, `rfBG`, `rfBR`, `lane CC` …).
- `ui-render-fx.js` — rfHD depth effects (Ambient Occlusion, floor shadow, still-view smoothing) on `UI.renderHooks`; see *Look: depth effects (rfHD)*.
- Load order (index.html): ui-core, ui-render-fx, ui-sketch, ui-commands, ui-holewizard, ui-panels, ui-app, ui-profiles, then ui-relations … ui-transform, ui-occt, drawing*. `boot()` runs on DOMContentLoaded, after every file.

- Kept builds (rfHO, ui-core.js before `rebuild`): `App.geom = { key, build }` = `geomKey(model)` (model JSON less `drawings`) of the model the build on screen came from (set by `noteGeom` after a kernel build; an OpenCascade swap of that build takes it over in `applyBuild`). `undo` / `redo` call `rebuild({ keepSame: true })`: same key, no rollback, nothing in flight -> `applyBuild(App.build, { kept: true })` reuses `App.mesh` (no kernel, no new mesh, drawing projections stay cached, OpenCascade's exact solid stays; ui-occt.js `afterBuild` ignores `kept`). ## How things are done here — the patterns to copy
- A feature command: imitate `cmdShell` — copy `existing` or make the feature JSON, `openPM({ title, icon, values: f, message, command: { onPick }, handles, groups: [{ title, fields }], onChange, onOK: function () { return commitFeature(f, existing); } })`. `commitFeature` pushes undo, assigns id / name, rebuilds, selects, writes the status. Then: tree icon in `FEATURE_ICON` / `featureIcon`, a case in `editDispatch`, a ribbon item, `UI.cmdX = cmdX` export.
- PM spec fields: `title`, `icon`, `values`, `groups[{ title, collapsed, show(v), fields }]`, `message` (HTML, yellow box) / `messageOk`, `onChange(v, key)`, `onOK(v)` (return `false` to refuse, a Promise, or `{ keepOpen: true, promise }`), `onCancel`, `onClose`, `okBlocked(v)` -> reason (greys ✓), `extraActions[{ title, icon, onclick }]` (✓+), `keepVisible` (pin), `noFocus` (sketch tool PMs), `keepSelection`, `command` (goes to `App.command`: `onPick`, `faceList`, `hoverItem`), `handles(v)`, `exprMap`, `onRollback`, `help`, `sketchTool` / `selectionPM` (Ctrl+Z undoes at once instead of cancelling).
- Field types (`renderField`): `number` (`key`, `label`, `unit: 'u'` = length in doc units / `'deg'`, `step`, `min`, `max`, `rerender`; takes `=` equations and shop input 3/8, 1-1/2, 25mm), `select` (`options` or fn), `check` (`disabled`), `radio` (`options [[value, name]]`, `disabledOption`), `iconRadio` (`[[value, name, icon]]`), `text`, `static` (`value`), `pick` (`value`, `placeholder`, `icon`, `active(v)`, `onActivate`, `items(v)` list with `onRemove` / `onClear`), `buttons` (`[{ label, onclick, active }]`), `html`.
- Two-Enter rule (`pmEnter`, lane BP): Enter in a box typed in since focus / last Enter commits that entry (reformats, status "… press Enter again to finish"); Enter with nothing pending is ✓ and closes, also keepOpen / ✓+ commands (`pmOK({ close: true })`). Any typing counts (ui-app.js `input` listener). Graphics-area Enter routes here too. A custom box: call `UI.pmEnter(inp, commitFn)`; `commitFn` returning `false` refuses.
- One-Esc rule (`UI.escapeCommand()`, ui-commands.js, lane CG): one Esc ends the active command completely from any focus (PM box or list, unit / on-screen box, Modify box, Instant3D box, gnomon box, graphics area): `UI.escapeBoxes` hooks close value boxes unapplied → the sketch tool goes down (`cancelTool`: pulled segment gone, placed ones kept) → `pmCancel` (✗) → `UI.escapeTools` hooks (a drawing's tool). A command's own Esc handler calls `UI.escapeCommand()` (register a hook for a new box; never write another copy). Exceptions keep their own Esc and `preventDefault` it: modal dialogs, open menus / flyouts / the view cube / the level popup (close first, one press), in-place editors that are not commands (tree rename, table / title-block cells, command search); ui-app.js skips an Esc that is `defaultPrevented`. Dynamic Mirror is a mode, not a command: the Esc after the tool is down turns it off.
- ✓+ (Mastercam Apply): `extraActions: okPlus(apply, after)` — imitate ui-transform-3d.js `okPlus`.
- Ribbon item: `{ id, label: 'Two\nLines', run, tool, icon, help, key, active(), dyn(), extra, group, wide }`; `{ sep: true }`; `{ stack: [items], grid, cls }`; `{ fly: 'name', label?, items: [...] }` (face = last used, `localStorage anvil.fly.<name>`). No `run` and no `tool` = SolidWorks' command, greyed with "Not available in Anvil yet". `extra: true` = Anvil's own, goes to » first. `group: 'Zoom'` = Mastercam caption under the buttons (laid out by ui-transform.js `captions()`). Imitate `viewTab()` in ui-panels.js. A tooltip without `help` reads `RIBBON_HELP[label]`.
- A new tab: add `RIBBON.Name = [...]` (and `ASM_RIBBON` if assemblies get it); other files use `UI.RIBBON` / `UI.ASM_RIBBON`; tab visibility per document goes through `UI.ribbonTabsFor`.
- Menus (trap, lane FC): `UI.menuHook` is NOT a safe chain for part menus: drawing-ui-panels.js line ~495 replaces it without calling the earlier hook, so a hook set in ui-commands.js is lost. Add part menu rows in `partMenus()` itself (one `.concat(UI.x ? UI.x() : [])`).
- Menus: `partMenus()` returns `[{ label: 'File', items: [{ label, action, key, icon, checked, disabled, dimmed, sep, items }] }]` (`dimmed` (rfIP): greyed `.mi-dim` but still runs: File ▸ a recent document not found, whose click asks Remove / Keep; smoke `rfIP.js`); extend with the chained `UI.menuHook` (`var base = UI.menuHook; UI.menuHook = function (m) { var out = base ? base(m) : m; … }`).
- Icon: add `I.myIcon = p(...) + ln(...) + …` in icons.js using the palette constants (`S` ink = currentColor, `M` construction grey, `B` secondary ink #6d6d6d (rendered as the ink at 70 %), `G` green OK, `R` red cancel, `FY / FYL / FYD` feature yellow, `F1 F2 F3` solid greys, `P` reference grey, `W` paper) and helpers `p`, `ln`, `circ`, `ell`, `rect`, `pt`, `txt`, `blk` (45° oblique block). 16 × 16 grid, one drawing for every size: follow *Look: icons (rfGZ)* at the end. Never blue. Alias with `I.b = I.a`.
- Colours: chrome via CSS variables (`--panel`, `--line`, `--text`, `--muted`, `--sel`, `--hover`, `--blue` (now grey #3a3a3a, the name is historic), `--cm-*` CommandManager, `--icon-ink`, `--msg-*`, `--pick-active` magenta); set both `:root` and `:root[data-theme="dark"]`. Viewport colours in ui-core.js `LINE_PALETTE` / `mats`.

## Traps
- Test renders into a `WebGLRenderTarget` must call `UI.render()` first: thick lines (fat twins of `LineSegments`) take their material's clipping planes only in the app's own render pass; a section rendered without it shows the clipped edges (rfFO).
- A `.clone()` of a line material copies `userData.fatMats` (the cached thick twins) as plain objects and throws in `syncFatMat`: make a new material and `lineMat(m, w)` it.
- Pinholes: the BSP booleans leave T-junctions; seen face-on through a plate the background showed through single pixels (Parametric plate, Top). The crack filler hides them; the mesh itself still has them (kernel).
- Colour rules (2026-10-13, user; chrome part lifted 2026-11-12, see *Look: colour scheme*): the CHROME now has one blue accent; icons and the graphics area keep the old rules below. Was: grey-black UI chrome, no blue in the UI (X / Y / Z axes red / green / blue are the only exception). The no-blue rule is for the UI only, not for solids (user 2026-11-03): model shading, materials, reflections and appearances may carry blue (rfHA's "no blue on the shaded part" step is a look pin, not a rule); graphics area grey-black in both themes (`#viewport` overrides `--viewport`); model edges white in Wireframe / HLR / HLV, #161616 on shaded faces; sketch geometry white, construction #a8a8a8 dashed; selection #ffd400 yellow dashed (`LineDashedMaterial`, 7 / 4 px); selected faces / solids a light-blue tint #7ec8ff @0.45 (`mats.sel`, user 2026-10-27), pre-highlight orange #ff9a2e; end points green #2ee66b beads; default part #8c8c8c (`Materials.DEFAULT_COLOR`); preview of Transform commands magenta. rfBQ / rfBU / rfCD fail on any blue you add.
- Section View is per document (rfHF): `loadModel` clears `App.view.section` (and refreshes the HUD), so New Part, File ▸ Open, `anvil.load` / `anvil.run` (a script run replaces the document) and Edit Part / return to assembly start uncut; `rebuild()` / undo keep it. A test that wants a section after loading a model must open it after the load.
- Menus (rfHF, style.css block `/* rfHF menus */` at the end): `showMenu` marks a menu with icons `.mi-icons` and each row with one `.mi-has-ico`; `.chk` and `.mi-ico` are fixed 16 px boxes (flex none, overflow hidden) side by side, rows without an icon get 24 px after the check. No `:has()` needed (rfGX's `:has` rule gives the same 24 px).
- `UI.undo()` closes every PM and rebuilds; call `UI.undoCommand()` for user-facing undo. `pushUndo` before mutating `App.model`, `autosave` after; undo stores whole-model JSON (60 steps).
- `commitFeature` returns a Promise; tests must await it (`await UI.pmOK(); await idle()`).
- `closePM` deselects sketch entities unless `spec.keepSelection`. `openPM` while an Edit Feature is rolled back rolls forward first.
- The two-Enter rule arms boxes at render and focus: a re-render keeps a pending entry, but a box you replace by hand must be armed (`UI.pmArm`).
- `UI.setStatus` is overwritten by later commands; undo writes "Last step undone.".
- Group captions are laid out by a MutationObserver in ui-transform.js, not by the ribbon renderer (a known hack): a tab with `group` items needs ui-transform.js loaded.
- `ui-app.js` loads before ui-sketch-*.js, ui-transform*.js and drawings: those extend `UI` later, so ui-app code must call them through `UI.x` at run time, never alias at load.
- Ribbon items are found by tests by `id` and `label`: renaming breaks tests; keep both.
- Default units are inches (`UI.defaultUnits`); PM defaults in mm go through `UI.lenDefault(mm)` (shop fraction in an inch document).

## Look: adaptive quality (rfHE)

## Depth, lines and whole faces (rfHY, lane zoomsmooth, 2026-11-05)
