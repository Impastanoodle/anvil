## Entry points — the functions / builders / script API and key internals
Script API (part script, `p` = Builder):
- `p.sheet(T, R, K, opts)` — sets `model.sheet` through `makeSheet`. opts: `bendAllowanceType` (`kfactor` | `allowance` | `deduction` | `table`), `bendAllowance`, `bendDeduction`, `bendTable`, `gaugeTable` + `gauge` (null T / R / K come from the gauge row).
- `sketch(...).….end().baseFlange(T?, opts)` (also `p.baseFlange`) — extrude of depth T with `sheetBase: true`; makes a sheet if none, else edits only what it is given.
- `p.flange(L, [[x,y,z], …], opts)` — points on straight edges of a flat sheet face. opts `angle` (90), `reverse`, `toward` (world dir, overrides reverse), `radius`, `position`, `lengthRef`, `miter`, `miterGap`, `relief`, `reliefWidth`, `reliefDepth`, `bendAllowance: { type, value }`.
- `p.hem(L, edges, { hemType, hemPosition, gap, hemRadius, hemAngle, reverse })` — a `flange` with `hem: true`, angle 180.
- `p.jog(H, L, edges, opts)` (edge jog, old parts); lane DC `p.jog(offset, { sketch, fixed, offsetRef: 'outside' | 'inside' | 'overall', angle, position (Sketched Bend's), reverse, radius, bendAllowance })` and `sketch(...).line(...).jog(offset, opts)` (sketch jog); `p.cut(d, { linkT: true })`; `p.sketchedBend(angle, { sketch, fixed, position, reverse, radius, bendAllowance })` (also on SketchBuilder); `p.cut(d, { normalCut: true })`.
- `p.breakCorner(size, [[x,y,z] on corner edges], { kind: 'chamfer' (default) | 'fillet', faces: [[x,y,z] on flat sheet faces], name })` — Break-Corner/Corner-Trim.
- `p.unfold(fixedFace | null, bends | null)` / `p.fold(bends | null)` — bends are points on bends of the FOLDED part (`K.sheetBends(...)[i].at`); null / [] = all.
- `p.closedCorner([[x,y,z] on end faces], { cornerType: 'butt' | 'overlap' | 'underlap', gap (0.01 in / 0.25 mm), ratio (1), coplanar (true), name })`; `p.sheet(T, R, K, { relief: 'rect' | 'obround', reliefRatio })` — Auto Relief.
Kernel (`Kernel.*`):
- `flatPattern(model, build, mesh)` — the blank (see Data shapes). `exportDXFFlat(flat, units, opts)` — laser DXF text.
- `bendCalc(sheet, angleRad, R, T, custom)` — THE bend math: `{ BA, BD, type, source, value, K, warning }`.
- `bendAllowance(θ, R, T, K)`, `outsideSetback(θ, R, T)`, `bendDeduction(θ, R, T, BA)`, `bendTableLookup(table, T, R, deg)`.
- `makeSheet(o)`, `sheetParams(model)`, `sheetKFactor(sheet)`, `sheetNote(sheet)`, `gaugeTable(ref)`, `gaugeRow(ref, gauge, units)`, `gaugeTables`, `DEFAULT_GAUGE_TABLE`.
- `bendNoteText(bend, units, { prec }?)` (`UP 90° R.060`), `bendNotePlace(bend, h)`.
- `flangeLayout(f, model, ctx)` → `{ parts, cuts, info, section }` (plain data, both kernels build it); `buildFlange`; `buildJog` → `{ first, second }`; `flangeProfile(A, R, T, L, ov)`; `hemSection(type, A, R, T)`.
- `sketchedBendLayout` / `buildSketchedBend` → `{ body, tool }`; `normalCutTool(tool, body, model, dir)`.
- Cuts across a bend: `bendVoids`, `wrapCut`, `bendZoneMap`, `bandSlabSpec` (OpenCascade reuses them).
- Closed Corner: `closedCornerLayout(f, model, { body })` → `{ adds, cuts: [{ loop, plane, a, b }], corners: [{ at, d, faceAt }] }` (plain data, both kernels), `buildClosedCorner` → `{ add, cut }`, `closedCornerName`, `CLOSED_CORNER_TYPES`, `closedCornerDefaultGap(model)`, `closedCornerMinGap(model)`; `AUTO_RELIEF_RATIO` 0.5.
- Break Corner: `breakCornerLayout(f, model, { body })` → `{ tools: [{ plane, pts, seg, curves, a, b }], corners }` (plain data, both kernels), `buildBreakCorner` (the cut tool), `breakCornerCandidates(body, model)` (the corners a part offers: `{ at, top, bot, faces, alpha }`), `breakCornerName(model)`, `BREAK_CORNER_KINDS`.
- Unfold / Fold: `buildUnfold` / `buildFold(f, model, ctx)` → `{ body, recs, state, cut }`; `sheetBends(model, build, mesh)` → `[{ at, angle, R, len, ba }]`, `sheetBendAt(bends, P, T)`, `unfoldedBendAt(unfoldRec, P, T)` (a click on a flat strip), `unfoldPreview(model, build, f)`. `flatPattern(..., { trace })` fills `trace.faces` (key, 2D map, tracked n / w, outer loop, parent strip) and `trace.strips` (record, `id: { feature, index }`, BA, A2 / B2 / o2, strip polygon, parent face).
- Flat hygiene: `cleanFlatLoop`, `snapFlatCircle`, `flatCircleTol`, `flatOptions.merge` (`'2d'` default | `'csg'`).
- Constants: `FLANGE_LENGTH_REFS`, `HEM_TYPES`, `SKETCHED_BEND_POSITIONS`, `BEND_ALLOWANCE_TYPES`, `DEFAULT_K_FACTOR` 0.5, `LEGACY_K_FACTOR` 0.71, `CLOSED_HEM_RADIUS` 0.02 (×T), `DEFAULT_HEM_ANGLE` 270.
Internals worth knowing: `hemCrossing` (refuses crossing hems), `coplanarBody` + `EDGE_PICK_TOL` (edge picks within 0.75·T), `planeFaces` (face grouping for the unfold), `faceComponents` (unfold one connected piece at a time), `bendSurfaceNotches`, `mergeFlatRegions` / `csgMerge`, `flatEtch`, `sketchedBendRecords`, `zoneBA` / `customBA`, `sheetCorners` / `cornerSection` / `straightLoop` (Break Corner).
Lane DC: `buildSketchJog(f, model, ctx)` → `{ body, tool, g }` (two `buildSketchedBend`s: the first at the line, the second on a synthetic sketch `jog2` on the moved face, `reverse` flipped, Bend Outside, BA − shift + g further; records `rec1 + [{ jogSplit }] + rec2`, read by `flatPattern` through `sketchJogRecordSets`), `jogMinOffset(A, R, T, ref)`, `isSketchJog`, `JOG_OFFSET_REFS`; `flatBody(model, build, flat?)` → `{ body, flat, plane, h0, h1 }`; `_.linkThickness(model)` (kernel-rebuild.js: resolved `linkT` cuts get depth T, blind; also in `cacheFromBuildModel`).
UI: `UI.toggleFlatten(on?)`, `UI.cmdFlatPatternEdit`, `UI.flatRefuse`, `UI.updateFlatState`, `UI.flatShown`, `UI.cmdBaseFlange`, `cmdSheetMetal`, `cmdEdgeFlange`, `cmdMiterFlange`, `cmdHem`, `cmdJog`, `cmdSketchedBend`, `cmdBreakCorner`, `cmdFlatten`, `exportFlatDXF`, `cmdDxfOutput`, `dxfOutput`, `dxfToDwg`.

## How things are done here — patterns to copy
- **Bend math**: always through `bendCalc` (custom BA wins over the sheet's method). BA = θ·(R + K·T); OSSB = (R+T)·tan(θ/2) up to 90°, R + T beyond; BD = 2·OSSB − BA; an L with outside dims A, B unfolds to A + B − BD. Entered BA / BD apply at every angle (warning off 90°); tables interpolate by angle, tolerance 0.5 % of T / R, fall back to K with a warning.
- **Sheet parameters**: written only through `makeSheet` (fixed key order, `kFactor` always stored). Kernel code reads `resolvedModel(model).model.sheet`; UI code reads `previewModel().sheet` (resolved), never raw `App.model.sheet` numbers.
- **New sheet feature end to end** (CLAUDE.md list, sheet flavour): layout function returning plain data like `flangeLayout` → CSG builder like `buildFlange` → a `rebuildModel` switch case like `'flange'` (`pickBody`, build, subtract `ctx.flangeCut`, `putBody`) — body-editing, so not `buildTool`; add to `needsSheet` and to the `featureKey` regex if BA changes the solid; one record per bend in `ctx.flanges[f.id]` (plain arrays only: they cross to the worker by structured clone) that `flatPattern` consumes — emit edge-flange-shaped records (`kind: 'edge'`) as Sketched Bend does, so the unfold needs no new code; `NAME_BASE` in `featureName`; Builder method + `generateScript` case (round picks to 1e-4, `nv()` for equations); `cmdX(existing)` with `openPM` → `commitFeature`, Custom Bend Allowance fields like `cmdSketchedBend` (`useCustomBA`, `cbaType`, `cbaK`, `cbaBA`, `cbaBD`); `editDispatch` case; `FEATURE_ICON` / `featureIcon` + `icons.js`; `RIBBON['Sheet Metal']`; worker preview op in `worker.js` (`'flange'`, `'jog'` exist); OpenCascade: `SUPPORTED` + an op like `flangeOp` (else the feature is 'unsupported' and Anvil's solid stays); kernel + smoke group files.
- **A sheet feature that only removes material** needs no `kernel-rebuild.js` edit: register it as a cut from its own file, `K.registerFeature(type, { build, cut: true, script })` (Break Corner does, at the end of kernel-sheetmetal.js; Hole Wizard is the other model). `buildTool` builds it, `isCut` reads `cut`, `generateScript` writes `script(f, v, idVar, optsStr)`, the worker's `'tool'` preview op works unchanged, and `applyCut` warns on a no-op. `NAME_BASE` does not know registered types (it gives `Feature1`): name the feature yourself (`breakCornerName`) in the Builder method and the PM. Tag curved sides with `prism(loop, plane, a, b, shared, cv)` (`cv[i] = { c, r }` per arc chord) so `massProps` is exact and the flat's chords stay equal (≤ 22.5° each, ≥ 3) for `dxfLoopCurves` to write one ARC.
- **Unfold** (`flatPattern`): base face = largest face parallel to the base sketch plane (sketch side wins unless the other is 10 % larger; a Sketched Bend anchor overrides) → `unfold` recursively: each flange record attached to an unfolded face adds a strip of length BA beyond its edge, then its wall face (real outline, holes) goes in with a rigid map. The strip is exactly [0, BA] (CW: its old 1e-3 overlap of base and wall showed through any hole reaching a bend line, 119.998 for 120; the `eps` in the strip / stand-in code is now 0 and the 2D merge's 1e-4 weld joins the seams). Regions merge in 2D (`mergeFlatRegions`, weld 1e-4; `csgMerge` fallback); reliefs, `cutouts` and `bendSurfaceNotches` are notches; every loop then `cleanFlatLoop` + `snapFlatCircle`. Bend line = mid-strip; `up` from the tracked inner side.
- **Unfold / Fold** (DB): no second unfold. `flatPattern(…, { trace })` gives every face piece's rigid 2D map; `ufFaceMotion` makes it a 3D motion F (folded → flat 3D: `ufFlat` puts the tracked surface on the base face, depth into the sheet), Q per piece (flat → unfolded state: the parent's across an unfolded bend, `Q_p·F_p·F_c⁻¹` across one left folded), P = F_fix⁻¹·Q_fix⁻¹ keeps the fixed face. All bends: body = the blank × T (faces tagged with the Unfold's id, so face sketches refer to it) moved by P; some: pieces (blank ∩ face prisms, strips; B0 ∩ `ufWedge` for folded bends) unioned. Fold: removed = unfolded body − now; per face piece moved back rigidly; per unfolded strip the voids (`bendVoids`, ends on) wrapped by `wrapCut` with the bend's section frame (`ufBendFrame`: origin on the inner face at the bend start, x = o, y = u, n = a→b), and recorded as `{ kind: 'foldCutouts', feature, index, cutouts }` in `ctx.flanges[fold.id]`; `flatPattern` merges them into those records (`foldCutouts`), so the flat hole is exact and `bendSurfaceNotches` skips it. A Fold of some bends re-runs `unfoldState` on the folded result for the rest.
- **`bendSurfaceNotches`** (CW): reads BOTH bend surfaces (tracked Rt and the other; CW2: the other surface only adds gaps the tracked one has nothing of, so a Normal Cut's hole is the tracked footprint, smooth, not the union with the far surface's per-facet stair), each polygon unrolled on its own by angle (s = BA·θ/A, same station on both) and the band less their union is the gap; a gap is kept where the part has air at mid-thickness (`keep`). A polygon counts when every corner is in the radius band and the bend's angles and its plane faces the axis (normal within 25° of radial) — OpenCascade's triangles round a hole are tilted, and the old "plane holds the axis" test dropped them (the flat fell in two). Faces' outlines are not used: `faceOutline` lost a facet piece next to a zero-area polygon a Normal Cut leaves.
- **DXF** (`exportDXFFlat`): layers OUTLINE (loop 0), HOLES (other loops; round → CIRCLE), BEND (bend lines), NOTES (each bend's `label` centred along its line via `bendNotePlace`; the sheet note + `BLANK W X H IN|MM` below the blank), ETCH (marks; colour from the sketch layer, default ACI 3). R12 default, R2000 for DWG; `style` polyline | entities; blank's lower-left at 0,0; `$INSUNITS` 1 in / 4 mm. Check with `dxf-check` (headless does it on every `--dxf-flat`).
- **Exact vs mesh**: flat sizes are analytic (assert to 1e-9). Anvil's bends are faceted, so solid volumes are not π-exact: compare with the polygon section (`K.flangeProfile` area × edge length, as `mitred-corners-and-bend-reliefs.js` does) or `nearRel(blankArea·T, volume, 2e-3)` (`rfBW.js`).
- **OpenCascade Normal Cut** (`normalCutTool` in occt-kernel.js, CW): same rules as Anvil's — sheet faces of body ∩ tool, plus the backward shadow (tool start cap swept against dir; body ∩ it; entry sheet faces touching a chosen one join), planar → prism, bend face → `MakeThickSolidBySimple(face, −(T+eps))`. The probes use the exact surface point / normal at each triangle's UV centroid (`BRepGProp_Face.Normal`): a chord centroid sits a sagitta off a 16 ga bend, more than the 1e-3·T probe, so the inside surface never read as a sheet face. No joint wedges: the exact bend is tangent to base and wall. Removed volume is exact (occt-tests row, 2e-8).
- **OpenCascade**: `flangeOp` runs `K.flangeLayout(f, m, { body: shapeToCSG(body) })` and sweeps exact arcs; BA never changes its solid except through cuts across bends (voids re-read from the exact solid). The flat is computed from whichever mesh drives (`App.mesh`), so anything in `flatPattern` must work on a face-tagged OpenCascade mesh too (`occt-flat.js`).

## Traps — things that broke before
- **Mirrored blank / UP read DOWN** (rfBW #14): a cut made one sheet face a hair larger and "largest face wins" flipped the flat. Base face choice gives the sketch side a 1.1 factor; keep it when touching face selection.
- **Countersink in the flat** (rfBW #25): the far face fills what it still has under a hole, so CSK / CBORE leave the through hole and a blind pocket leaves nothing.
- **Hemmed panel / pan lips** (rfBW #10–11): one mesh face can hold several separate coplanar pieces; the unfold works per connected piece (`faceComponents`) and a flange takes only pieces its wall starts on. The unfold only walks base → wall, never back, so every piece of the base face nothing reached is laid with the base map afterwards (rfCJ: a window across a channel bottom running into both bends lost the far half and its flange). The Sketched Bend anchor pass uses the same 1.1 side rule as the plain pass (rfCJ: it kept the old 1e-6 tie-break and a pocket flipped the notes).
- **Bend-strip tab at a corner notch** (rfCJ): `bendSurfaceNotches` drops a gap at a bend's end only while a flange meets that end (a relief here, or a record ending within 3 (R + T) whose bend still has metal there); otherwise the gap is a cut through the bend's end and the mid-thickness test decides. The end exclusion exists because a neighbour's relief slot bites this bend's start and the eps bridge would nick the base corner.
- **A cut that only thins a bend** (rfCW, rfCJ): a cut from the top face into an up-bend takes the outside surface only; the flat notches it to where that surface is cut (≈ 60° of a T = R bend), unrolled by angle, so blank × T no longer equals the solid there (the blank drops the bite through the thickness). A Normal Cut's hole is the tracked footprint (CW2): ~36 points, two sharp corners at the wall line, the base half disk one ARC; the far surface of Anvil's faceted bend steps at every facet and is ignored where the tracked surface is cut.
- **Cut across a bend made after the flange** (rfBW #12–13, p9-cutbend): the strip must not bridge it; `bendSurfaceNotches` unrolls what the bend surface lacks. Cuts made before the flange are wrapped by BA (`bendVoids` / `wrapCut`) — so BA changes the solid; `featureKey` puts the whole sheet in the key of bend features (the `hem` in its regex is dead: hems are type `flange`).
- **Material Inside corner trim** (rfBZ): the trim overshoots 0.01 only where the sheet stops; it used to nick the next bend by 0.016 in. Material Inside at angles other than 90° trims R + T regardless (unconfirmed vs SolidWorks; `virtualSharp` trims (R+T)·tan(θ/2)).
- **Crossing hems** are refused by `hemCrossing` ("would cross: shorten one or add a relief") — a CSG union would self-intersect.
- **Inch edge picks** (r12/inchflange12): `meshFromBody` groups faces by plane rounded to 0.01 units; 0.075 / 0.125 in sheets split the top face, the pick fell on the bottom edge and the flange folded down. `coplanarBody` + picks within 0.75·T; OpenCascade's `shapeToCSG` gives one plane per B-rep face and a 0.05 mm chord in model units.
- **Corrupt flat DXF on OpenCascade** (`faceOutline` weld): vertices on a 1e-4 rounding midpoint lost their twin and chained two holes together; now a neighbour-cell weld (`flat-weld.js`). Relief slivers of bend face on a wall plane: `planeFaces` never puts a curved (`polygon.surf`) facet in a plane.
- **K = 0.71** is a shop MIB constant, not a K-factor (true K = 0.452). Examples and old parts store 0.71 (flat warns "outside 0–0.5"); a sheet with no stored K uses `LEGACY_K` 0.71, a new one 0.5. Do not "fix" stored K values.
- **Script vs UI defaults differ**: script flange without `lengthRef` = `'wall'` (legacy; L is the straight wall), UI new flange = `'outer'`; script hem without `hemType` = open, Bend Outside, UI new hem = Closed, Material Inside. Keep scripts' meanings when changing UI defaults.
- **Closed hem** folds at 0.02·T (a solid needs a radius); its BA is π·(0.02·T + K·T). Jog `height` is the inside offset (riser = H − 2R); jog is edge-based (SolidWorks uses a sketch line). OpenCascade's jog keeps only the first bend's cuts.
- `bendCalc` throws when BD > 2·OSSB (negative BA). Bend table misses fall back to K with a `flat.warnings` entry, not an error.
- **R12 → DWG** makes an empty DWG through LibreDWG: `dxfToDwg` refuses R12; always convert from R2000. DWG needs `serve.ps1`'s `api/dxf2dwg`.
- Records in `ctx.flanges` must be plain arrays / numbers (worker structured clone); no CSG, no functions.
- **Break Corner corners** (`sheetCorners`): a convex outline vertex of a flat face that has its opposite sheet face T behind (outward normals: `w + w' = T`), interior angle ≤ 150° (so arc chords and line–arc tangent points never count), both edges free at mid-thickness (`pointTester` probes 0.25·T outside / inside), T thick at the corner. The corners a chamfer leaves are 135° and can be broken again; the vertex where a wall meets its bend is not a corner (the bend is solid just past it). A pick that no longer finds a corner is an error, never skipped.
- **Corner edges are tiny on screen**: corner edges are T long, so a click must land on the edge's own mid (pickEdge takes the nearest edge within 7 px; the long outline edges meet at the corner). The PM refuses a long edge with a hint; a face click is the easy way to take all of a face's corners.
- **Closed Corner frame** (rfCS): the end face's longest straight edge is the wall height (h), w across; the matching face is the nearest antiparallel flat face within 10·T + 2·R whose h range overlaps; the extended part is the end face ∩ that h band (so the bend's end stays out: open bend region). The matching wall may cover the end (Material Inside: each later wall stops R short) or stop beside it (Bend Outside / Material Outside: it is then extended across). A face wider than 1.5·T is refused (a wall's big face across a narrow channel would otherwise "close").
- **Strip eps past BA** (rfCS): the flat's bend strip runs 1e-3 into the wall to weld; where the wall does not start on the start line (an Overlap trimmed the matching wall above its bend) that left a 0.001 step in the blank. `flatPattern` now notches the strip back to BA over the start-line stretches no wall piece runs along.
- **Builder.flange relief**: no `relief` option now means no `relief` field (the sheet's Auto Relief; none on a sheet without one); `generateScript` writes `relief: "none"` only when the sheet has an Auto Relief.
- **Unfold / Fold limits** (DB, DB2): through cuts only cross a bend (blind ones are carried on flat faces), bosses added while unfolded are not folded, one open Unfold at a time. While unfolded, `flatPattern` draws in the frame the Unfold moved the flat to (`rec.frame`, so a wall-fixed Unfold gives the folded flat's 2D) and adds the unfolded bends' lines / notes from the record (`ufOpenRecord` / `ufOpenBends`: `line` on the tracked surface, `toward`, `cba`). Mitred strips get exact `cutouts` (the band spans the trapezoid's τ range, `ufStripFrame`). OpenCascade (DB2, `unfoldOp` / `foldOp` in occt-kernel.js) builds both from `Kernel.unfoldStateAt(model, idx)` (an Anvil rebuild of the prefix gives F / Q / P and the strips): exact face pieces moved, flat strips × T; Fold cuts with `cylinderCutter` (flip the frame when x × y ≠ n). Unsupported there: a Fold of some bends, an Unfold of a bend that already has a cut across it, a Fold whose Unfold is not in the build or its cache.
- Not built yet (do not assume): Rip is a placeholder, no Flat-Pattern feature (Flatten is a dialog), Tear relief, Closed Corner between non-square flanges or closing the bend region, Welded Corner, Corner Relief, Break Corner on corners inside bends, Link to thickness, Miter Flange start / end offset, jog Outside Offset / Overall Dimension.
- **Unfold / Fold limits** (DB): through cuts only cross a bend (blind ones are carried on flat faces), bosses added while unfolded are not folded, one open Unfold at a time, mitred bend ends get no exact `cutouts` (the surface notch reads them), no OpenCascade build (unsupported: Anvil's solid stays). The flat pattern of a part left unfolded has no bend lines.
- Not built yet (do not assume): Rip is a placeholder, Flat-Pattern fixed face / grain direction, Jog Fix projected length, Tear relief, Closed Corner between non-square flanges or closing the bend region, Welded Corner, Corner Relief, Break Corner on corners inside bends, Miter Flange start / end offset.
- **Sketch jog offsets** (DC): inside = the facing faces (base top → flange bottom for a jog up), outside = inside + T (face to the same face), overall = inside + 2T; the straight riser g = (inside − 2R(1 − cos A) + T cos A) / sin A ≥ 0. Not confirmed against SolidWorks' icons; the edge jog's `height` is the inside offset.
- **UI exports in ui-core.js** go in the object it returns (`UI` is undefined while ui-core.js runs; `UI.x = …` at module level kills the boot). The *Solid Bodies* folder also has a row named Base-Flange1: find feature rows by `[data-fid]`.
- **Flatten is display only**: `App.mesh` / `App.build` stay folded (flat pattern, DXF, mass properties, drawings read them). A feature made while flat goes at the end of the list, i.e. above Flat-Pattern1, and acts on the folded part (DC2, as SolidWorks); faces of the folded part cannot be picked meanwhile (sketch on planes or fold first). Ribbon Flatten and Insert ▸ Sheet Metal ▸ Flatten both call `UI.toggleFlatten`. OpenCascade: `jogOp` sends a sketch jog to `sketchJogOp` (two `sketchedBendOp`s, the second on a synthetic `jog2` sketch passed as `extraSketches`; volume = the plate's exactly with K .5, occt-tests rows *Jog from a sketch line*).
