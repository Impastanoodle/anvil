# Sheet metal — agent map
Read this first; find line numbers with `grep -n <name> anvil/docs/INDEX.md`. Update this card at the end of any lane that touched this area (add what you had to dig for; fix what is wrong).

## Files — one line each: what the file owns
- `anvil/kernel-sheetmetal.js` — all sheet-metal geometry and math: `model.sheet` (makeSheet), bend allowance / deduction / bend tables / gauge tables, edge flange + hem + miter + reliefs (`flangeLayout` → `buildFlange`), jog, Normal Cut tool, cuts across a bend, Sketched Bend, Break Corner (`sheetCorners` → `breakCornerLayout` → `buildBreakCorner`, registered as a cut), Closed Corner (`closedCornerLayout` → `buildClosedCorner`, a rebuild case: adds + trims), sheet Auto Relief (`makeSheet` `relief` / `reliefRatio`, read in `flangeLayout`), the flat pattern, bend notes, Unfold / Fold (`unfoldState`, `buildUnfold`, `buildFold`, lane DB). No DOM.
- `anvil/kernel-rebuild.js` — the `flange` / `jog` / `sketchedBend` / `closedCorner` / `unfold` / `fold` cases of `rebuildModel` (Unfold's state rides in `ctx.unfold` and on each step as `step.unfold`, in memory only; a cache without it restarts at 0 when a feature after an Unfold must rebuild) (they are NOT `buildTool` cases), `needsSheet`, `featureKey` (adds `model.sheet` to the key of bend features), the Normal Cut swap in the default case, `ctx.flanges` / `ctx.flangeCut`.
- `anvil/kernel-script.js` — Builder `sheet` / `baseFlange` / `flange` / `hem` / `jog` / `sketchedBend` / `customBendAllowance`; `generateScript` (`p.sheet(...)` header; base flange is written as `p.extrude(T, { sheetBase: true })`; `flange` / `jog` / `sketchedBend` cases); `Builder.breakCorner` (its script line comes from the registered feature's `script`, not a `generateScript` case); `Builder.closedCorner` + its `generateScript` case (optsStr drops `false`: `coplanar: false` is spliced in by hand); Builder `unfold` / `fold` + their `generateScript` case; `exportDXFFlat`, `bendNotePlace`, the `DXF` writer, `dxfLoopCurves` (true arcs / circles from chords).
- `anvil/kernel-equations.js` — `resolvedModel`: sheet fields may be `"=expr"` strings; a bad one gives `sheetError`, which fails every feature that `needsSheet`.
- `anvil/ui-commands.js` — the PropertyManagers: shared groups `sheetGroups` / `sheetToValues` / `sheetFromValues` / `applyGauge` / `editGaugeTable` / `editBendTable`, `cmdBaseFlange`, `cmdSheetMetal`, `cmdEdgeFlange(existing, kind)` (kind `flange` | `miter` | `hem` | `jog`; `cmdHem` / `cmdJog` are wrappers; lane DL `cmdMiterFlange(existing, preEdges)` (the Miter Flange PM: Miter Parameters / Start/End Offset / Custom Bend Allowance / Custom Relief Type; an edge selected + no sketch opens a sketch on `{ custom, origin: the edge's nearer end (e.a without a click point), x: outward, y: face normal }` and comes back through `pendingAfterSketch`; an edge-only `miter` flange goes to `cmdEdgeFlange(…, 'miter')`; memory `mfLast`)), `cmdSketchedBend`, `cmdBreakCorner` (corner-edge / face picks, Chamfer / Fillet icons, session memory `bcLast`), `cmdClosedCorner` (end-face picks validated by `closedCornerLayout`, worker op `closedCorner`, memory `ccLast`), the *Auto Relief* group in `sheetGroups` (`autoRelief` / `reliefRatio`, `defaultSheet` = rect 0.5) and the Edge-Flange *Custom relief type* check (`useCustomRelief`; off = no `relief` field), `cmdFlatten` (the Flat Pattern dialog, `flatSvg`; tree ▸ Flat Pattern…), lane DC: `toggleFlatten` (ribbon Flatten, `model.flatState`), `flatRefuse` (in `commitFeature`: no new feature while flat), `cmdFlatPatternEdit` (Flat-Pattern1 PM), `cmdJog` → `cmdSketchJog` (sketch-line Jog PM; `cmdUnfoldFold(kind, existing)` (`cmdUnfold` / `cmdFold`, worker preview op `unfold` / `fold` = `K.unfoldPreview`); lane DI: `cmdRipFeature` (edge picks validated by `ripLayout`, Change Direction cycles the last pick's `direction`, memory `ripLast`), `cmdTab` / `tabPM` (`cmdBaseFlange` goes there when a `sheetBase` feature exists; the preview extrudes `K.tabFeature`'s resolved copy; `editFeature` does not treat a tab as the sheet's PM). Lane DQ: `cmdInsertBendsPM(kind, existing)` (`cmdInsertBends` / `cmdConvertSheetMetal`: sheetGroups reused, Insert Bends drops the gauges and shows T read from the part (`K.sheetThicknessAt` at the fixed face); Convert adds Bend Edges (edge clicks; lane rfIE: Collect All Bends button under the list = `K.convertSMCollect`, the list's changes are PM steps in `hist`, taken back by Ctrl+Z / Ctrl+Y through the generic `spec.pmUndo(redo)` hook (`pmUndoHook`: window keydown capture + wraps `UI.undoCommand` / `redoCommand`); 'buttons' fields take `disabled(v)` / `title`), Rip edges found, Corner Defaults (rip gap); preview `K.insertBendsPreview` on the main thread; on ✓ the sheet is written after its own `pushUndo`, so one undo takes both back), `toggleNoBends` (ribbon No Bends, `model.noBends`). - `anvil/ui-core.js` — lane DC: `updateFlatState` (Flatten's display: hides `groups.body` / `edges` / `highlight`, draws `Kernel.flatBody` + dashed bend lines in `UI.flatGroup`; `App.flat`, `App.flatError`, `App.flatBounds`; `pickFace` / `pickEdge` return nothing while flat; `modelBounds` takes the flat), called from `applyBuild`.
- `anvil/ui-app.js` — `anvil.flat()`, `anvil.dxfFlat()`, flat size in Custom Properties.
- `anvil/occt-kernel.js` — `flangeOp` / `jogOp` / `sketchedBendOp`: the same layouts built with exact bend arcs; `breakCornerTool` (the corner sections through `loopWire`, exact arcs); `closedCornerOp` (cut + fuse the layout's planar prisms); `shapeToCSG`.
- `anvil/drawing-views.js` — flat-pattern drawing view (`view.kind 'flat'`) calls `flatPattern` (see the drawing card). `nest.js` / `ui-nesting.js` nest flats.

## Entry points — the functions / builders / script API and key internals
Script API (part script, `p` = Builder):
- `p.sheet(T, R, K, opts)` — sets `model.sheet` through `makeSheet`. opts: `bendAllowanceType` (`kfactor` | `allowance` | `deduction` | `table`), `bendAllowance`, `bendDeduction`, `bendTable`, `gaugeTable` + `gauge` (null T / R / K come from the gauge row).
- `sketch(...).….end().baseFlange(T?, opts)` (also `p.baseFlange`) — extrude of depth T with `sheetBase: true`; makes a sheet if none, else edits only what it is given.
- `p.flange(L, [[x,y,z], …], opts)` — points on straight edges of a flat sheet face. opts `angle` (90), `reverse`, `toward` (world dir, overrides reverse), `radius`, `position`, `lengthRef`, `miter`, `miterGap`, `relief`, `reliefWidth`, `reliefDepth`, `bendAllowance: { type, value }`.
- `p.hem(L, edges, { hemType, hemPosition, gap, hemRadius, hemAngle, reverse })` — a `flange` with `hem: true`, angle 180.
- `p.jog(H, L, edges, opts)` (edge jog, old parts); lane DC `p.jog(offset, { sketch, fixed, offsetRef: 'outside' | 'inside' | 'overall', angle, position (Sketched Bend's), reverse, radius, bendAllowance })` and `sketch(...).line(...).jog(offset, opts)` (sketch jog); lane dxfout-2 `offsetEnd: 'upToVertex' | 'upToSurface' | 'offsetFromSurface'`, `offsetTarget` (point, or plane name / ref-plane id), `offsetDistance`, `offsetFlip` (offset `null`): `jogTargetOffset` in `jogBendFeature` turns them into the Blind offset (both kernels; occt `sketchJogOp` passes the body as CSG for the sheet side); PM `cmdSketchJog` has End condition + a target box (`tgActive`, `jogCmd.pickPlane` while it waits for a face / plane; vertices via `pickVertices`); `p.loftedBend([a, b], { method: 'bent' | 'formed', faceting: 'count' | 'length' | 'chord', facetValue })` (registered feature at the end of kernel-sheetmetal.js: `loftedBendLayout` → `buildLoftedBend` (closed mesh, vertices moved ±o, o = mitre / least squares of n·o = T/2), `loftedBendFlat` (flatPattern returns it when there is no Base Flange); PM `cmdLoftedBend`, ribbon button wired from ui-commands.js; tests `kernel/rfJJ.js`, `kernel/rfJJ-loft.js`, `smoke/rfJJ.js`; OpenCascade: unsupported); `p.cut(d, { linkT: true })`; `p.sketchedBend(angle, { sketch, fixed, position, reverse, radius, bendAllowance })` (also on SketchBuilder); `p.cut(d, { normalCut: true })`.
- `p.breakCorner(size, [[x,y,z] on corner edges], { kind: 'chamfer' (default) | 'fillet', faces: [[x,y,z] on flat sheet faces], name })` — Break-Corner/Corner-Trim.
- `p.unfold(fixedFace | null, bends | null)` / `p.fold(bends | null)` — bends are points on bends of the FOLDED part (`K.sheetBends(...)[i].at`, or a still-folded bend's `at` / a click on it as shown, for a second Unfold); null / [] = all. A second Unfold while one is open is fine (DJ).
- lane DL `p.miterFlange(edges, { sketch, position: 'inside' | 'outside' | 'bendOutside', radius, miterGap, startOffset, endOffset, relief, bendAllowance, name })` (also on SketchBuilder) — Miter Flange from a profile sketch; `K.miterFlangeStages(f, model, ctx, run)` plans it (both kernels), `buildMiterFlange` (Anvil, via `buildFlange`'s first line), `miterFlangeOp` (occt-kernel.js, via `flangeOp`).
- `p.closedCorner([[x,y,z] on end faces], { cornerType: 'butt' | 'overlap' | 'underlap', gap (0.01 in / 0.25 mm), ratio (1), coplanar (true), closeBend (DK2: absent = open, unlike the PM's default), name })`; `p.flatPattern({ fixedFace, grain: { at, dir } })` (DK2; written after the features); sketch jog `fixLength: true`; `p.sheet(T, R, K, { relief: 'rect' | 'obround', reliefRatio })` — Auto Relief.
- `p.rip([[x,y,z] | { at, direction }], gap, { direction: 'both' | 'side1' | 'side2', name })`; `sketch(...).rect(...).end().tab({ reverse, name })` (lane DI; both Builder methods live in kernel-script.js).
- `p.vent({ sketch, boundary, ribs, spars, fill (entity indices of the sketch), ribWidth, sparWidth, fillWidth (0), radius (0), name })`, also `sketch(...).….end().vent(opts)` (lane DT); no boundary = auto groups (largest closed entity = boundary, lines = ribs, other closed / arcs = spars).
- lane open-base: `sketch(...).polyline(pts, false).end().baseFlange(null, { depth (1 in / 25 mm), midplane, reverse (depth), flip (thickness side), radius })` — Base Flange from an open chain of lines (`K.isOpenProfile(sketch)` decides, in the Builder and `cmdBaseFlange`); the PM is `cmdOpenBase(sid, existing)`, previewed on the main thread with `K.buildOpenBase`.
Kernel (`Kernel.*`):
- Cross-Break (rfGK): cosmetic. `p.crossBreak(face, { radius (sheet R), angle (1), reverse, sketch, name })`, also `p.sketch(...).line(...).crossBreak(face, opts)` (the sketch's solid lines replace the X; `.end()` returns the part, so call it before `.end()`). `crossBreakLayout(f, model, { body, sketches, planes })` → `{ refgeo: 'crossBreak', plane, n, at, lines: [{ a, b }], corners, radius, angle, reverse }`; a `rebuildModel` case keeps the body and stores it in `ctx.planes[f.id]` (like reference geometry; no flange record, so `flatPattern`'s unfold never sees it). `crossBreakFlat` (one hook line after `flatEtch`) adds `{ t: 'line', a, b, crossBreak: id, up, angle, R, note }` to `flat.etch`, so Flat-Pattern orientation moves them; `exportDXFFlat` takes them OUT of ETCH: BEND lines (`bendLines`) and one `CROSS BREAK UP 1° R.060` on NOTES (`notes`), on the first line's first half, clear of the crossing. UP = raised toward the side the flat is seen from (picked face's normal, unless `reverse`). The drawing's flat view shows them as its thin green etch lines and (lane drawing, 2026-11-04) the note beside the crossing (`crossBreakNote`, key `cb:<id>`, drawing-render.js `cbNotePrims`). PM `cmdCrossBreak(existing, back)`; `drawCrossBreaks` (a `UI.onBuild` hook, `UI.crossBreakGroup`, also called by `toggleFlatten`) draws them on the model or the flat. Edit Cross-Break Sketch makes a sketch on the face holding the lines, before the feature when editing. OpenCascade: not in `SUPPORTED` yet.
- Forming Tool (rfHI, lane forming): `p.formingTool(tool, facePoint, { at: [u, v] (face sketch frame, K.planeFromFace), angle, flip, ...dims, name })`; `FORMING_TOOLS` (dimple, extrudedHole, louver, lance, rib: `{ id, label, help, params: [{ key, label, unit, value (in), mm, help }] }`), `formingToolDefaults(id, units)`, `formingToolName`. `formingToolGeometry(tool, dims, T)` = the tool in its own frame (u length, v across, z out of the face, sheet z ∈ [−T, 0]): section paths (points + `{ c, r }` arcs; sharp corners offset by T with `ftOffset`, which refuses a form too tight for T) as revolves (dimple, extruded hole; rib ends = two 180° half revolves) or prisms (louver hood + two end walls T thick outside the opening, lance bridge, rib middle); each section runs T past the footprint onto the sheet (overlap, no coincident faces). `formingToolLayout(f, model, { body })` finds the face (`ftSheetFaces`: flat faces with the opposite face T behind), refuses unless the face holds the `clear` polygon (footprint + T: off an edge, over a hole or another form, across a bend), builds 3D frames, and `rec` (plain data: fill polygon, marks, centre mark, lances, pierce, note). `buildFormingTool` = (body − footprint prism through T) ∪ the sections (`smBool`), built with `_.buildRevolve` / `_.buildExtrude` of synthetic sketches so cone / torus / cylinder records make `massProps` exact (tests: Pappus to 1e-12). Rebuild case `formingTool` (kernel-rebuild.js, in `needsSheet`) stores `rec` in `ctx.planes[f.id]` (refgeo 'formingTool'), the formed solid in `ctx.tools`. Flat: `formingFlat` (before the merge) pushes the fill as a region (the formed area is plain blank), lance slits `FT_SLIT` 0.01 in wide as notches (closed loops on HOLES), the extruded hole's pierce (r = bend start − BA(90°, ri) − straight collar) as a notch, and etch items `{ form: id, kind: 'mark' | 'note' }` that `exportDXFFlat` writes on FORM (ACI 6) / NOTES, never ETCH. Registered (`cut: false`) for its `script`. PM `cmdFormingTool(id, existing)` (Tool iconRadio, face click = centre, Position X / Y, Rotation angle, Reverse direction, dims with `show` per tool, main-thread preview, memory `ftLast`); ribbon flyout `forming` (items ftDimple … ftRib); `drawCrossBreaks` also draws the FORM marks on the flat. OpenCascade: not in `SUPPORTED` (Anvil's solid stays). Not built: radii on dimple / rib / lance corners, louver ends other than square walls, custom tools from a part.
- Rip / Tab (DI): `ripLayout(f, model, { body })` → `{ tools: [{ plane (origin O on the outside corner line, x n1, n = d), pts, a, b, side, length }], corners }` (plain data, both kernels), `buildRip`, `RIP_DIRECTIONS`, `ripDefaultGap`; registered cut `'rip'` (+ `NAME_BASE.rip`). `tabFeature(f, model, plane, body)` → the resolved copy (depth T, blind, `reverse` = into XOR away), called by `rebuildModel`'s default case and OpenCascade's `extrudeTool`.
- Vent (DT): `ventLayout(f, model, { body, sketches, planes })` → `{ plane, a, b, boundary: [loop], keep: [{ outer, holes }], groups }` (loop = `{ pts (CCW), seg, curves: [{ c, r, full }] }`, plain data, both kernels), `buildVent` (boundary prisms − keep prisms run 50 % past both faces), `ventAutoGroups(sketch)`, `ventFlowArea` → `{ open, boundary, percent }`; registered cut `'vent'` (its `script` writes `p.vent`), `NAME_BASE.vent`. Every full circle goes through `ventCircleLoop` with a vertex wherever a strip edge or another circle crosses it (`ventLineHits` / `ventCircleHits`), so each chord the cut keeps is a whole chord tagged as a cylinder: `massProps` exact to 1e-12 and the flat's arcs come out as DXF ARCs. Rib / spar line ends lying on the boundary / a spar / the fill run on by half the width. OpenCascade: `ventTool` (same layout, `loopWire` exact circles). DT2: `radius` = `ventFillets(boundary, keep, r, e)`: every convex corner of the open region (curve pairs: straight edges and circles, intersections; exactly one of the four probes round the point open) gets a kept piece = the corner less the fillet disk (offset curves meet at its centre, tangent points are the feet), its fillet chords tagged `{ c, r }`, its other sides run e (≤ a quarter of the narrowest strip) into the metal; tangent points on a `{ circle }` wrapper go to its `breaks`, so the kept chords stay whole: exact (1e-14 on the acceptance vent, 28 corners), DXF ARCs, OpenCascade exact through the same loops (`ventTool` unchanged). A fillet that does not fit is an error. Insert ▸ Features ▸ Fastening Features ▸ Vent runs `UI.cmdVent` (ui-panels.js partMenus; menu labels are flat strings with ▸). Not built: rib / spar depth and offset (sheet metal: T and 0), draft.
- `flatPattern(model, build, mesh)` — the blank (see Data shapes). `exportDXFFlat(flat, units, opts)` — laser DXF text.
- `bendCalc(sheet, angleRad, R, T, custom)` — THE bend math: `{ BA, BD, type, source, value, K, warning }`.
- `bendAllowance(θ, R, T, K)`, `outsideSetback(θ, R, T)`, `bendDeduction(θ, R, T, BA)`, `bendTableLookup(table, T, R, deg)`.
- `makeSheet(o)`, `sheetParams(model)`, `sheetKFactor(sheet)`, `sheetNote(sheet)`, `gaugeTable(ref)`, `gaugeRow(ref, gauge, units)`, `gaugeTables`, `DEFAULT_GAUGE_TABLE`.
- `bendNoteText(bend, units, { prec }?)` (`UP 90° R.060`), `bendNotePlace(bend, h)`.
- (lane drawing, 2026-11-04) every `flatPattern` bend has `id: '<feature id>:<n>'` (n = the record's index in `build.flanges[feature]`; `flangeIds[k]` in flatPattern, `sketchedBendRecords(...).added` for Sketched Bend / Jog, an open Unfold's records carry `src`). The drawing keys dragged bend notes by it (`bend:<id>`).
- `flangeLayout(f, model, ctx)` → `{ parts, cuts, info, section }` (plain data, both kernels build it); `buildFlange`; `buildJog` → `{ first, second }`; `flangeProfile(A, R, T, L, ov)`; `hemSection(type, A, R, T)`.
- `sketchedBendLayout` / `buildSketchedBend` → `{ body, tool }`; `normalCutTool(tool, body, model, dir)`.
- Cuts across a bend: `bendVoids`, `wrapCut`, `bendZoneMap`, `bandSlabSpec` (OpenCascade reuses them). Lane FU: `wrapRegion(loops, sec, BA, plane, t0, t1)` = the bend's METAL (band less the voids) built directly, no boolean; `bendSector(sec, plane, t0, t1)` = the bend's sector to cut out; `_.smBool(a, op, b | [b…], T)` = a boolean at scale 2^round(log2 1/T) (bit-exact back).
- Closed Corner: `closedCornerLayout(f, model, { body })` → `{ adds, cuts: [{ loop, plane, a, b }], corners: [{ at, d, faceAt }] }` (plain data, both kernels), `buildClosedCorner` → `{ add, cut }`, `closedCornerName`, `CLOSED_CORNER_TYPES`, `closedCornerDefaultGap(model)`, `closedCornerMinGap(model)`; `AUTO_RELIEF_RATIO` 0.5.
- Break Corner: `breakCornerLayout(f, model, { body })` → `{ tools: [{ plane, pts, seg, curves, a, b }], corners }` (plain data, both kernels), `buildBreakCorner` (the cut tool), `breakCornerCandidates(body, model)` (the corners a part offers: `{ at, top, bot, faces, alpha }`), `breakCornerName(model)`, `BREAK_CORNER_KINDS`.
- Unfold / Fold: `buildUnfold` / `buildFold(f, model, ctx)` → `{ body, recs, state, cut }`; `sheetBends(model, build, mesh)` → `[{ at, angle, R, len, ba }]`, `sheetBendAt(bends, P, T)`, `unfoldedBendAt(unfoldRec, P, T)` (a click on a flat strip), `unfoldPreview(model, build, f)`. `flatPattern(..., { trace })` fills `trace.faces` (key, 2D map, tracked n / w, outer loop, parent strip) and `trace.strips` (record, `id: { feature, index }`, BA, A2 / B2 / o2, strip polygon, parent face).
- Flat hygiene: `cleanFlatLoop`, `snapFlatCircle`, `flatCircleTol`, `flatOptions.merge` (`'2d'` default | `'csg'`).
- Constants: `FLANGE_LENGTH_REFS`, `HEM_TYPES`, `SKETCHED_BEND_POSITIONS`, `BEND_ALLOWANCE_TYPES`, `DEFAULT_K_FACTOR` 0.5, `LEGACY_K_FACTOR` 0.71, `CLOSED_HEM_RADIUS` 0.02 (×T: only the floor of an open hem's radius now; closed hems use `CLOSED_HEM_GAP_MM` 0.1, tear drops `TEARDROP_CLEAR_MM` 0.2, `hemMM(model)` = 1 mm in model units), `DEFAULT_HEM_ANGLE` { teardrop: 200, rolled: 270 }.
Internals worth knowing: `hemCrossing` (refuses crossing hems), `coplanarBody` + `EDGE_PICK_TOL` (edge picks within 0.75·T), `planeFaces` (face grouping for the unfold), `faceComponents` (unfold one connected piece at a time), `bendSurfaceNotches`, `mergeFlatRegions` / `csgMerge`, `flatEtch`, `sketchedBendRecords`, `zoneBA` / `customBA`, `sheetCorners` / `cornerSection` / `straightLoop` (Break Corner).

## How things are done here — patterns to copy
- **Bend math**: always through `bendCalc` (custom BA wins over the sheet's method). BA = θ·(R + K·T); OSSB = (R+T)·tan(θ/2) up to 90°, R + T beyond; BD = 2·OSSB − BA; an L with outside dims A, B unfolds to A + B − BD. Entered BA / BD apply at every angle (warning off 90°); tables interpolate by angle, tolerance 0.5 % of T / R, fall back to K with a warning.
- **Sheet parameters**: written only through `makeSheet` (fixed key order, `kFactor` always stored). Kernel code reads `resolvedModel(model).model.sheet`; UI code reads `previewModel().sheet` (resolved), never raw `App.model.sheet` numbers.
- **New sheet feature end to end** (CLAUDE.md list, sheet flavour): layout function returning plain data like `flangeLayout` → CSG builder like `buildFlange` → a `rebuildModel` switch case like `'flange'` (`pickBody`, build, subtract `ctx.flangeCut`, `putBody`) — body-editing, so not `buildTool`; add to `needsSheet` and to the `featureKey` regex if BA changes the solid; one record per bend in `ctx.flanges[f.id]` (plain arrays only: they cross to the worker by structured clone) that `flatPattern` consumes — emit edge-flange-shaped records (`kind: 'edge'`) as Sketched Bend does, so the unfold needs no new code; `NAME_BASE` in `featureName`; Builder method + `generateScript` case (round picks to 1e-4, `nv()` for equations); `cmdX(existing)` with `openPM` → `commitFeature`, Custom Bend Allowance fields like `cmdSketchedBend` (`useCustomBA`, `cbaType`, `cbaK`, `cbaBA`, `cbaBD`); `editDispatch` case; `FEATURE_ICON` / `featureIcon` + `icons.js`; `RIBBON['Sheet Metal']`; worker preview op in `worker.js` (`'flange'`, `'jog'` exist); OpenCascade: `SUPPORTED` + an op like `flangeOp` (else the feature is 'unsupported' and Anvil's solid stays); kernel + smoke group files.
- **A sheet feature that only removes material** needs no `kernel-rebuild.js` edit: register it as a cut from its own file, `K.registerFeature(type, { build, cut: true, script })` (Break Corner does, at the end of kernel-sheetmetal.js; Hole Wizard is the other model). `buildTool` builds it, `isCut` reads `cut`, `generateScript` writes `script(f, v, idVar, optsStr)`, the worker's `'tool'` preview op works unchanged, and `applyCut` warns on a no-op. `NAME_BASE` does not know registered types (it gives `Feature1`): name the feature yourself (`breakCornerName`) in the Builder method and the PM. Tag curved sides with `prism(loop, plane, a, b, shared, cv)` (`cv[i] = { c, r }` per arc chord) so `massProps` is exact and the flat's chords stay equal (≤ 22.5° each, ≥ 3) for `dxfLoopCurves` to write one ARC.
- **Unfold** (`flatPattern`): base face = largest face parallel to the base sketch plane (sketch side wins unless the other is 10 % larger; a Sketched Bend anchor overrides) → `unfold` recursively: each flange record attached to an unfolded face adds a strip of length BA beyond its edge, then its wall face (real outline, holes) goes in with a rigid map. The strip is exactly [0, BA] (CW: its old 1e-3 overlap of base and wall showed through any hole reaching a bend line, 119.998 for 120; the `eps` in the strip / stand-in code is now 0 and the 2D merge's 1e-4 weld joins the seams). Regions merge in 2D (`mergeFlatRegions`, weld 1e-4; `csgMerge` fallback); reliefs, `cutouts` and `bendSurfaceNotches` are notches; every loop then `cleanFlatLoop` + `snapFlatCircle`. Bend line = mid-strip; `up` from the tracked inner side.
- **Unfold / Fold** (DB): no second unfold. `flatPattern(…, { trace })` gives every face piece's rigid 2D map; `ufFaceMotion` makes it a 3D motion F (folded → flat 3D: `ufFlat` puts the tracked surface on the base face, depth into the sheet), Q per piece (flat → unfolded state: the parent's across an unfolded bend, `Q_p·F_p·F_c⁻¹` across one left folded), P = F_fix⁻¹·Q_fix⁻¹ keeps the fixed face. All bends: body = the blank × T (faces tagged with the Unfold's id, so face sketches refer to it) moved by P; some: pieces (blank ∩ face prisms, strips; B0 ∩ `ufWedge` for folded bends) unioned. Fold: removed = unfolded body − now; per face piece moved back rigidly; per unfolded strip the voids (`bendVoids`, ends on) wrapped by `wrapCut` with the bend's section frame (`ufBendFrame`: origin on the inner face at the bend start, x = o, y = u, n = a→b), and recorded as `{ kind: 'foldCutouts', feature, index, cutouts }` in `ctx.flanges[fold.id]`; `flatPattern` merges them into those records (`foldCutouts`), so the flat hole is exact and `bendSurfaceNotches` skips it. A Fold of some bends re-runs `unfoldState` on the folded result for the rest.
- **`bendSurfaceNotches`** (CW): reads BOTH bend surfaces (tracked Rt and the other; CW2: the other surface only adds gaps the tracked one has nothing of, so a Normal Cut's hole is the tracked footprint, smooth, not the union with the far surface's per-facet stair), each polygon unrolled on its own by angle (s = BA·θ/A, same station on both) and the band less their union is the gap; a gap is kept where the part has air at mid-thickness (`keep`). A polygon counts when every corner is in the radius band and the bend's angles and its plane faces the axis (normal within 25° of radial) — OpenCascade's triangles round a hole are tilted, and the old "plane holds the axis" test dropped them (the flat fell in two). Faces' outlines are not used: `faceOutline` lost a facet piece next to a zero-area polygon a Normal Cut leaves.
- **DXF** (`exportDXFFlat`): layers OUTLINE (loop 0), HOLES (other loops; round → CIRCLE), BEND (bend lines), NOTES (each bend's `label` centred along its line via `bendNotePlace`; the sheet note + `BLANK W X H IN|MM` below the blank), ETCH (marks; colour from the sketch layer, default ACI 3). R12 default, R2000 for DWG; `style` polyline | entities; blank's lower-left at 0,0; `$INSUNITS` 1 in / 4 mm. Check with `dxf-check` (headless does it on every `--dxf-flat`, cut layers OUTLINE / HOLES / RELIEF). Lane dxfout (kernel `rfJF.js`, smoke `rfJF.js`), all off by default: `boundaryBox` (BOUNDARY, ACI 4, `curvesBox` corners), `bendLayers: 'split'` (BEND_UP 3 / BEND_DOWN 30 from `up`, cross-breaks too), `reliefLayer` (RELIEF 2: each strip's relief notches ride on its bend as `bend.reliefs`, polygons in the bend line's frame (`bendLocal` in flatPattern, `fromLocal` in the writer) so flatOrient moves them with no code; `reliefPieces` splits outline lines along notch edges, that loop goes out as LINE / ARC whatever the style), `hiddenEdges` (HIDDEN, ACI 8, LTYPE HIDDEN via `d.layer(n, aci, { hidden })`: `ftHidden(f, model, T)` in formingFlat puts the far-side outline on the tool's first mark as `farR` / `farPts` (mark-frame), so the drawing's etch never sees it). PM rows / headless flags `--dxf-boundary --dxf-bend-layers --dxf-relief --dxf-hidden`. No one-file-per-body: one sheet-metal flat per part.
- **ETCH marks** (`flatEtch`, kernel-sheetmetal.js; lane DP): marks of sketches on a sheet face (base, wall, or T behind it, mirrored) go through that face's unfold map; already in the DXF (ETCH layer, R12 / R2000) and the drawing's flat view (drawing-render.js, `v.showEtch`). A mark that runs off its face over a bend is cut at the bend edge (`etchSplit`, bisection on the mark's parameter) and the part over the bend projected along the sketch normal onto the bend surface on the sketch's side (Rt tracked / Ro other side) and unrolled by angle, s = BA·θ/A (`etchDeveloper`; `flatPattern` records `etchStrips` { fi, BA, Rt, Ro, startMap, wallMap, A2, B2, o2 } per strip, matched to the face by map identity). Under 90° it continues onto the wall (BA + ℓ); past 90° the rest is dropped with a warning. Developed pieces are a LINE when straight, else a polyline. Tests `kernel/rfDP.js`.
- **Exact vs mesh**: flat sizes are analytic (assert to 1e-9). Bend facets are chords but carry cylinder records (lane FX, rfFX): `bendCv(loop, c, radii)` / `secCv(loop, sec)` hand `prism` the `{ c, r }` of every chord of radius R / R + T (flange, hems, jog, Miter Flange stages, Sketched Bend, Insert Bends wedges with c = [0, 0]); `wrapRegion` tags its caps itself and places in-zone points at the TRUE angle on the chord (`chordAt`), so Fold is exact too. So `mp.volume` is exact: at K 0.5 folded volume = flat area × T to 1e-9 (rfFT M rows match OpenCascade to ≤ 3e-8, except M18: Normal Cut holes are faceted, 2.5e-5, and M26: a round void's wall inside the bend is its polygon, 1.2e-5); `mp.polygonal.volume` / `body.volume()` stay the faceted number (the `flangeProfile` area × length rule still holds for those, `consistentVolume`). A curved-face test (`p.surf`) now also skips bend facets (sheetCorners, closed corner, planeFaces, sketch-on-face refusal). Drawings: a mitre seam between two bends is an intersection chain on the true cylinders, a sagitta behind its own facets, so `hiddenIntervals` takes `skip: { faces }` for chain pieces on Anvil's solid (the Tray's seams reach the corner). Tests that pin a faceted section (`flangeProfile` area, sin δ/δ, wedge areas) compare `polyVol(r.mp)`.
- **OpenCascade Normal Cut** (`normalCutTool` in occt-kernel.js, CW): same rules as Anvil's — sheet faces of body ∩ tool, plus the backward shadow (tool start cap swept against dir; body ∩ it; entry sheet faces touching a chosen one join), planar → prism, bend face → `MakeThickSolidBySimple(face, −(T+eps))`. The probes use the exact surface point / normal at each triangle's UV centroid (`BRepGProp_Face.Normal`): a chord centroid sits a sagitta off a 16 ga bend, more than the 1e-3·T probe, so the inside surface never read as a sheet face. No joint wedges: the exact bend is tangent to base and wall. Removed volume is exact (occt-tests row, 2e-8).
- **OpenCascade**: `flangeOp` runs `K.flangeLayout(f, m, { body: shapeToCSG(body) })` and sweeps exact arcs; BA never changes its solid except through cuts across bends (voids re-read from the exact solid). The flat is computed from whichever mesh drives (`App.mesh`), so anything in `flatPattern` must work on a face-tagged OpenCascade mesh too (`occt-flat.js`).

- **Edge-flange mitre = SolidWorks' (lane rfIS, report 2026-11-02 5d)**: `flangeLayout`'s bisector branch sets `en.swMiter = { tB, ext, slope, wall }` for plain edge flanges (not hems, not a Miter Flange's stages): default gap `ccDefaultGap` (.01 in / .25 mm); each wall cut square to itself along the line where the gap-offset bisector meets its INSIDE face (`wall` plane; `part.wallClips` in Anvil, `part.clips` in OpenCascade when the slope ≤ 0, else `part.wallCuts`); the bend's end a helicoid from the base corner (τ = tB) to that line (`part.tapers`, linear in (s, t); `tails` stop the overlap strip). The record carries `miterLines: [{ ext, slope } | null]`; `flatPattern` runs the line on across the bend zone (r.t0 = ext − slope·BA), the strips' union meets past the corner (SolidWorks' outline exactly). SolidWorks' folded part is 3.9e-4 / 8.1e-4 under its own blank × T and Anvil's matches it within 1e-5 (the residual: SolidWorks' free-form end face). `part.endCuts`: the overlap strip's sliver past an acute free corner of the sheet, cut from the tool (both kernels).
- **Flange options (lane rfIZ, PM audit 2026-11-05)**: `flangeLayout` reads `lengthEnd: 'upToVertex'` + `lengthVertex` + `lengthVertexMode` ('normal' | 'parallel'; L computed in the first edge's frame, lengthRef ignored), `position: 'tangentToBend'` (shift R + T, ≥ 90°), `offset` ({ end: 'blind', distance } | number: `shift −= d`; a negative shift moves the origin out and grows `ov`, so the overlap strip is the sheet's extension in both kernels), `relief: 'tear'` (rect slit `ripDefaultGap` wide and deep; also `sheet.relief: 'tear'` in makeSheet), `reliefRatio` on a custom relief. Hems mitre (`miter` + `miterGap` on `hem: true`): `hemCrossing` tests the clipped sweeps. Builder.flange / Builder.hem (kernel-script.js) do not pass these fields yet; rfIZ sets them on the JSON. Miter Flange: stage 1 is `miterSquare` for any profile; later stages carry `swJoin` and find a corner where the two edge lines cross (`joinV`, the square-ended walls stop T + g/√2 short), then take the SolidWorks mitre (`swMiter`, tB = 0) with the end face t − tB = e·(1 − cos θ)/(1 − cos A) on `SWJ_CHORDS` chords.
- **Trim side bends + Corner Relief (lane smtrim, tests `kernel/rfJD.js`, `smoke/rfJD.js`, occt rows `smtrim:`)**: `trimSideBends` (Edge Flange, Miter Flange's first stage; not hems) works where `flangeLayout`'s trim-back finds `cont` (metal past an end = an earlier bend running on): `sideBendTrim` finds that edge record (its line ∥ o, lying past the end, P on its start line) and pushes its bend sector over the last `shift` of its length (exact radial planes from the axis to R + 1.5T, both kernels' plain prism) into `cuts`; no relief at that end (`en.sideTrim`); the side strip comes back by `ccExtend` records on the new flange's first record (`rec.sideTrims`, applied in flatPattern's flange branch through `ccExtendRecords`, which now compares ids as strings). Bend Outside trims nothing. OpenCascade: `smFlanges` (occt-kernel.js) keeps flange records by id for this, passed as `ctx.flanges`. Corner Relief: `bendCorners` pairs edge records square to each other folding the same way whose start lines cross at P near both ends (corner frame x = A.o, y = B.o, the face at x, y ≤ 0); `cornerReliefLayout` clips the shape (`cornerReliefShape`, convex) to the face (prism through T), each strip (a rectangle → radial `sector` prism; else `wrapCut`) over the record's span and each wall (prism in the wall frame, s − BA); strip parts go to the flat as `foldCutouts` records in `ctx.flanges[cr.id]` (flatPattern: `cornerRelief` branch → `foldCutouts`), face / walls from their outlines. Registered cut (`script` splices `centeredOnBend: false`, which optsStr drops); OpenCascade `cornerReliefTool` (prisms, `wrappedCutter`). PM `cmdCornerRelief` (main-thread preview, `crLast`), Corners flyout row, `FEATURE_ICON.cornerRelief`. Not built: 3 Bend corners (a U channel from an open-profile Base Flange plus Edge Flanges on the base's and a wall's end edges builds and makes one: the U bend and both end bends meet), non-square corners.
- **Welded Corner (lane smcorner, tests `kernel/rfJP.js`, `smoke/rfJP.js`, occt rows `smcorner:`)**: `weldedCornerLayout(f, model, { body })` → `{ adds: [{ loop, plane, a, b }], corners }` (plain data, both kernels; OpenCascade `weldedCornerTool`, fused). Pick = a point on a wall's END face (flat, through T: the two longest parallel straight edges T apart give A's sides and its straight h range); B = the nearest flat face facing back (normal −ne) at 0 < aIn ≤ 10T + 2R whose h range meets A's and whose w range starts within dMax of A's strip; weld = [0, aIn] × A's thickness ∪ [aIn, aIn + T] × [wOut, wB] (B's inside face's near end; the corner square and B's own gap after a Butt Closed Corner), over the common h range: the bend region stays open. `fillet` = a 16-chord quarter round in the inside corner (aIn, wIn), on SolidWorks' *sharp interior corner* reading (unsure; check against SolidWorks). `addTexture` stored only. Registered boss (`cut: false`). Flat: `flatPattern` (no `opts.trace`) with any unsuppressed `weldedCorner` returns `weldFreeFlat`: the model with them `suppressed`, `K.rebuild(m2, build.cache)`, memo on the non-enumerable `build.__weldFree`; so the flat is byte-identical to the part's without welds on both kernels. - **Closed Corner d = 0 (rfIS, 5c)**: an end face flush with the other wall's inside face is swapped for that wall's end (`ccSwap` in `closedCornerLayout`; work items are a growing list, `wk.swapped`): SolidWorks' blank to the digit.
- **Miter Flange** (DL): `miterProfile` reads the sketch into virtual sharps (lines chained end to end; an arc between two lines is that joint's radius: inner radius when the profile is the bend's inside face, r − T when outside); `miterFlangeStages` finds the profile's edge (a sharp edge parallel to the sketch normal within 1.01·T of an end of the chain; that end is the start), works in that edge's (o, u) frame, and runs stage 1 as an ordinary flange (`lengthRef: 'inner'`, `toward: u`, `startAt` + offsets) and each later line as a Bend-Outside flange (`lengthRef` absent = wall) on the previous walls' end edges: the pick is the end-face edge on the side the next line turns to (so no per-edge `toward` is needed); wall = D − setbacks, setback = R·tan(A/2) where the profile is the bend's inside face, (R + T)·tan(A/2) outside (material stays on one side of the profile: Material Inside = the base side). Later stages pass `miterJoin` (gap + 1e-4): `flangeLayout` then joins wall-end edges that far apart, accepts mirrored fold directions (u_j = u_i reflected in the bisector) and extends the sweep by the whole section. Offsets: `miterOffsetEnds` moves the chain's two free ends in (the trim-back and the record shrink with them, so the base keeps its corner beyond and an Auto Relief cuts there).
