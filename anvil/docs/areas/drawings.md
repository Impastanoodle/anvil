## Files — one line each: what the file owns
Engine (`Drawing`, no DOM; loaded by index.html, tests/kernel-tests.html, drawing-worker.js `importScripts`, headless/load.js), in load order:
- `drawing.js` — creates `Drawing` and the hidden `Drawing._` privates; view orientations (`ORIENTS`, `frameOf`, `projectedFrame`, `sectionFrame`), view-independent model edges (`meshEdges`, `joinCollinear`).
- `drawing-curves.js` — true curves from the kernel's analytic records (`meshCurves`): circles, arcs, ellipses, cylinder / cone silhouettes, surface intersections.
- `drawing-hlr.js` — `projectView(mesh, frame, {display, tangent})`: exact hidden-line removal against front-facing triangles; `fitArcs`, chains.
- `drawing-views.js` — section (`sectionOf` exact CSG cut, `hatchPattern` ANSI31…38, `hatchAssign`), detail (`clipProjection`), auxiliary / crop / break / broken-out / relative views, flat-pattern data (`flatData`, `bendNoteText`), `reattachDim`, and the drawing-sketch engine (`addSketchEntity`, `addSketchDim`, `setLineFormat`, `hideEdge`).
- `drawing-sheet.js` — `FORMATS` / `SCALES` / `ANSI_SCALES`, `newDrawing`, `addView`, projection cache + lazy mode (`_.LAZY`, `sectionJob` / `putSection`), `standard3View`, `layout`, projected / section / detail / flat views, title block (`TB_FIELDS`, `$PRP` links), sheet format editing, templates, tables, revision table, multi-sheet (`addSheet`, `sheets`, `activateSheet`), `autoDims` / `modelItems`, `fmtDim` / `inchText` / `dimStyle`, BOM and balloons, `drawingFile` / `readDrawingFile`.
- `drawing-annotations.js` — centre marks / centrelines (+ `autoInsert`), hole callouts (`holeInfo`, `holeText`), ordinate / baseline / chamfer dims, `numText` / `dimLabel` / `DIM_PROPS` / `setDimProps`, `dimSource` / `driveDim` (model dims drive the part), balloons, hole tables, symbols (finish, datum, GD&T), notes, `smartDim` / `addSmartDim`, `flatAnnotation`, `annotationPrims`.
- `drawing-render.js` — `compute(doc, mesh, model, ctx)` -> paper primitives; ANSI dimension drawing; text metrics (`textRect`, Century Gothic, `CAP_EM`), `STROKE`; writers `toSVG` / `svgParts` (one patchable group per layer), `toDXF` (R12 / R2000, layer per view), `toPDF` (one page per sheet). Loads last.
- `drawing-worker.js` — off-thread `projectView` / `sectionJob` (messages `mesh`, `project`, `section` -> `projected`, `sectioned`, `failed`).
UI (only when `UI` exists; share state through `UI.drawingInternal`, alias `DW`; the document state object is `D`):
- `drawing-ui.js` — makes `DW` and `D`; drawing icons (`DI` table that wraps the global `Icons`); doc state, open / close / detach, sheet DOM with pan / zoom, `render` (sheet recomputed, SVG patched per layer, views dropped in from the worker), `settle` / `ready`, hit testing (`viewAt`, `dimAt`, `entityAt`), the mouse.
- `drawing-ui-tools.js` — every command and tool: Standard 3 View, Model View (`startPlacing` / `placePending`), Projected / Section / Detail / Flat views, view & sheet properties, Model Items, exports (`exportAs`, `saveDWG`), annotation tools and their PMs, Smart Dimension (`smartDimClick`), Dimension PM (`cmdDimensionPM`, `applyDimensionPM`), arrow flipping, inline text edit, dimension dragging with snapping, BOM, Auto Balloon.
- `drawing-ui-panels.js` — drawing FeatureManager (`renderTree`), View Layout / Annotation / Sheet Format ribbon tabs (`UI.RIBBON[...]`), `UI.ribbonTabsFor`, `UI.menuHook`, keys, `window.anvil.drawing` API + `summary()`, `UI.drawing`, `UI.makeDrawing / openDrawing / closeDrawing / drawingActive`, Edit Sheet Format, templates, General Table, revisions, symbols, `UI.undoCancelsPM` chain.
- `drawing-ui-sketch.js` — the drawing's Sketch tab (rfAO): Line / Centerline / Rectangle / Circle / Arc / Spline / Point / Text on the sheet or in a view, relations, Smart Dimension on sketch entities, Line Format, Hide / Show Edges, Relative View (`DW.sk*` hooks called before drawing-ui.js mouse handling). Not in CLAUDE.md's drawing lane list, but it is this area.
- `drawing.css` — sheet desk / shadow, sheet tabs, drawing FeatureManager; `--dw-hot` amber hover / selection.

## Look rules (rfHB, 2026-11-03, user: "clean, sharp and professional") — keep them
- Screen line weights: `MIN_PX` / `devPx(c)` in drawing-ui.js `strokeFloor` set floors in whole DEVICE pixels: hairlines (thin, center, hidden, hatch, tangent, bend, etch) 1 device px (2 from 200 %), visible / chain `round(1.5 × dpr)` (2 / 2 / 2 / 3 device px at 1 / 1.25 / 1.5 / 2), thick one more. Paper widths (`STROKE`, drawing-render.js) unchanged: visible 0.5, thin 0.25, thick 0.7 mm. Never floor in CSS px (1.35 px at 150 % is a grey smear).
- Axis-aligned `<line>`s of the live sheet get `shape-rendering="crispEdges"` (`DW.crispLines`, run on every patched layer); slanted lines / arcs stay anti-aliased. Exports carry no crispEdges (rfHB checks).
- Overlay frames (view / annotation boxes) are `devPx('visible')` wide and crisp (drawing.css `#dw-overlay rect.dw-vbox…`).
- Sheet: a 1 px dark edge + a soft shadow (two `drop-shadow`s in `strokeFloor`), desk `--dw-desk` #b9b9b9 / #3a3a3a.
- Title block (drawing-render.js, `lab` / `val` / `big`): caption type 2.8 mm (capitals .08 in), values 3.5 mm, TITLE 6 mm; captions 1.5 mm in from the cell's top-left; values left on the same inset and centred in the room between the caption baseline and the cell bottom; tolerance lines capitals 2.2 mm, 1.75 × apart, 2.5 mm under the caption. Pinned in kernel rfHB + r13.
- Sheet tab bar: 24 px (rfHB2: do not change it, nor anything else that resizes `#drawing-sheet`: synthetic mouse events land on whole pixels and the smoke tests' drag tolerances (annotations, balloons, rfN, rfAL, rfAO) were met by the current pixel phase; a 28 px bar failed five of them), tabs hang from the bar's top line, inactive = bar colour with muted text, active = `--dw-tab-on` with a 2 px `--dw-tab-mark` line on top; bar colour follows `--sw-chrome`. Drawing tree rows copy the part tree's (`--sw-row-hover` / `--sw-row-sel` + hairline), hints 10.5 px muted tabular figures.

## Entry points — commands / API / key functions
- `anvil.drawing.make(opts)` — new drawing (or opens #0 if one exists; `{ fresh: true }` always adds one), Standard 3 View, returns `summary()`.
- `anvil.drawing.summary()` — `{ name, open, sheet, sheets, views[{ id, orient, kind, box, extents, stats, scale, flat… }], dims, notes, symbols, revisions, bom }`.
- `anvil.drawing.removedSection(parentId, { a, b, x, y, label, flip, scale })` (rfCX) — Removed Section, one undo step.
- `anvil.drawing.projectedView / sectionView / detailView / flatView / addView / deleteView / tangent` — views without the mouse, one undo step each.
- `anvil.drawing.centerMark / centerline / holeCallout / ordinate / baseline / chamferDim / note / symbol / balloon / autoBalloon / bom / titleBlock / modelItems / dimProps(i, props) / driveDim(i, v) / options / setSheet / addSheet …`.
- (lane CT) `anvil.drawing.horizontalDim / verticalDim(viewId, p1, p2, at)` (smartDim with `lock`), `horizontalOrdinate / verticalOrdinate(viewId, spec)`, `angularRunning(viewId, { base, refs, c?, cw?, rad? })`, `pathLength(viewId, { refs, lead? })`.
- (rfDD) `anvil.drawing.slotCallout(viewId, { c, r })` — Hole Callout on a slot (an end arc, or an arc slot's side arc).
- `anvil.drawing.svg(i) / dxf({ version: 'R12' | 'R2000', sheet }) / pdf()` — exports; DWG: `DW.saveDWG(sheet)` = R2000 DXF -> `UI.dxfToDwg` -> `DWG.fromDXF` (dwg-writer.js, AC1015, no server; POST `api/dxf2dwg` on serve.ps1 only as a fallback when the writer throws).
- `UI.drawing.{ state (D), render, ready(), settle(), standard3View, smartDimension, dimensionPM, modelView, sectionView, detailView … }` — the UI commands, for tests.
- Engine (no UI): `Drawing.newDrawing(model, opts)`, `standard3View(doc, mesh, units)`, `layout(doc, mesh, units)`, `compute(doc, mesh, model, { build, lazy })`, `toSVG / toDXF / toPDF(sheet)`, `addProjectedView(doc, mesh, parentId, dir, opts)`, `addSectionView`, `addDetailView`, `addFlatView(doc, mesh, { model, build })`, `addSmartDim`, `autoDims`.
- Headless: `node anvil/headless/anvil.js drawing <script|model.json> --svg o --dxf o --dwg o --pdf o [--views Front,Top,Right,Isometric] [--scale 1:2] [--dxf-version r12|2000]`.
- (rfIG, 2026-11-05) Smart Dimension takes a straight edge's **midpoint**: `pickAt` (drawing-ui-tools.js) returns `{ pick: { mid: [a, b] } }` when the pointer is within 6 px of the middle of the edge `entityAt` finds and has rested there (`sdMidReady`, the sketch's `UI.dimMidDwell()`; a quick click at the middle still picks the edge); `pickRef` (drawing-annotations.js) makes it `{ kind: 'pt', p, mid: <edge ref> }` and `reattachRef` finds the edge again and puts `p` at its new middle, so the dimension follows the part. The hover shows a descriptor box (`D.sdLabel`, `.dw-snap-label`: Midpoint, Vertex, Center, Edge, Circle, Arc, Ellipse) in `smartDimOverlay`. Smoke rfIG (drawing step).

## How things are done here — the patterns to copy
- (rfIF) Dimension PM / Hole Callout precision: `PREC_OPTIONS()` in drawing-ui-tools.js is None … .12345678 then "<drawing value> (Document)" (`auto`, from `Drawing.docOptions(doc).dimPrec`, default inch .123 / mm .12, "Fractions" when on); the Tolerance and Unit precision lists carry the part PM's icons (`dimTolType`, `dimPrecision`). `numText` and `setDimProps` take up to 8 places; Document Properties > Units > Decimal places offers Default + None … .12345678. `Drawing.inchText` / `dimStyle` take up to 8 too (kernel + smoke rfIF).
- Engine file shape: `(function (D, _) { … D.name = name; _.helper = helper; })(Drawing, Drawing._)`. Alias what an earlier file put on `_` (`var meshDiag = _.meshDiag;`); call later files' members through `_.name` / `D.name` (late bound). Reassigned state (`_.LAZY`, `_.DIMSTYLE`, `_.CTX`) is always read through `_`. Copy `drawing-views.js` top.
- A doc edit from the UI: `edit(function (dc) { … })` (settle, `UI.pushUndo`, `D.dirty`, `UI.autosave`, `render`); a placed view: `editView(fn)` (worker linework + auto insert). An API call: `annotApi(fn)` / `viewApi(fn)` in drawing-ui-panels.js (dry-run on a JSON copy first, so a throw leaves no undo step).
- A new annotation kind: engine `addX(doc, viewId, spec)` + `findX` / `deleteX` in drawing-annotations.js, primitives from `annotationPrims` (layer ANNOTATIONS), a tool `cmdX` + `xClick` in drawing-ui-tools.js (imitate `cmdCenterMark` / `centerMarkClick`), a tree row in `renderTree`, a ribbon item in `UI.RIBBON.Annotation`, an `anvil.drawing.x` entry.
- Two homes for annotations: on a view's geometry (`view.annotations`: centre marks, callouts, rfCU `cosmeticThread` / `dowelPin`, reattached with `reattachDim` each compute; `findAnnotation` / `editAnnotation` / `deleteAnnotation`) or on paper (`doc.symbols`: `SYMBOL_TYPES`, one `cleanSymbol` branch + one `symbolPrims` branch + `symbolText`; rfCU `datumTarget` / `leader` go through `CU_SYMBOLS` → `cleanCU` / `cuSymbolPrims`). Paper items follow a view through `followViews` (p, leader, and a leader's `jogs`).
- A tool with a PM: `toolPM(spec, toolName, pending)` + `RF_TOOLS[toolName] = clickFn` (the document capture listener routes sheet mousedowns); edits via `tryEdit` (dry run, one undo step). Copy the rfCU block (`cmdCosmeticThread`, `cuSymbolPM`, `cmdMultiJog`).
- A tool's live preview: put the tool name in drawing-ui.js mousemove's `/^(place|project|section|detail|culeader)$/` list (sets `D.pending.at`, redraws), and draw in a `DW.xOverlay(g, H, svgNode)` hook called from `drawOverlay` (class `dw-cut` for hot lines). Example: `cuLeaderOverlay` (rfCU2: placed points + live segment + arrow / dot, group `.dw-cu-leader`). The multi-jog leader's first click is its start (a note end), its last the arrow tip — the reverse of SolidWorks, which clicks the arrow first.
- (DW2) `UI.menuHook`: drawing-ui-panels.js runs the hook set before it first (`DW.menuHookBase`, unwrapped from drawing-ui-tools.js' onAssign wrapper via `g._inner`); a part-side module may set `UI.menuHook` before the drawing files load.
- `onAssign(obj, key, fix)` can be used once per key: a second call replaces the first setter, so later assignments skip the first fix. Add to the existing fixes (`UI.RIBBON.Annotation` rfAD, `UI.menuHook` rfN, `DW.cmdSymbol` / `DW.symbolMenu` rfAN) instead.
- New ribbon tab or menu row: chain the hook — `var base = UI.menuHook; UI.menuHook = function (m) { var out = base ? base(m) : m; … return out; }` (same for `UI.ribbonTabsFor`); imitate drawing-ui-sketch.js.
- Text sizes and arrows come from the dimension style (`D.dimStyle(doc)`, `_.DIMGEO`: .125 in on inch, 3.5 mm on mm). Never hard-code 3.5 mm (rfBX).
- Numbers on the sheet: `fmtDim` / `numText` (ANSI inch: no leading zero, trailing zeros kept, `2X`, `Ø`, `R.060`); scales: `scalesFor(doc)` (ANSI set for inch), `scaleLabel` ('SCALE 2 : 1') vs `scaleText` ('2:1').
- A dimension's paper geometry: primitives carry `dimIx`; hit-test with `Drawing.textRect(prim)`.
- A new dimension kind (lane CT): engine record + measure + `reattachUserDim` branch in drawing-annotations.js; its paper primitives from a function the render's `dimPrims` hands off to at its top (`_.ctDimPrims`), `dimText` in drawing-sheet.js, `dragDim` / `cmdDimensionPM` (`single`, group `show`) in drawing-ui-tools.js. A new click tool needs no drawing-ui.js dispatch: register it in `RF_TOOLS[tool]` (capture mousedown, drawing-ui-tools.js); add its name to drawing-ui.js's hover regex (`entityAt` pre-highlight) and draw picks from a `DW.*Overlay` hook.
- Ribbon flyout: `{ fly: 'dwDim', items: [...] }` (the Annotation tab's Smart Dimension; the list is `CT_DIMS` in drawing-ui-panels.js, also Tools ▸ Dimensions). The face is the last pick, remembered in localStorage: a test that picks from it resets it with `UI.ribbonFlyFace('dwDim', 0)`, or later `ribbonButton('Smart Dimension')` finds nothing.

## Data shapes
- Doc (in `App.model.drawings[i]`, saved with the part): `{ name: 'Draw1', sheet: { name, format: 'ANSI B', scale: [1, 2], autoScale, projection: 'third', paper? }, units, views: [], date, autoDims, suppressed: [], nextView, layout: 'auto', options: {}, bom, bomRows, … annotations, notes, symbols, sheets, activeSheet, properties }`.
- Dimensions (view.dims), lane CT: Horizontal / Vertical = a linear `h` / `v` with `lock` (two picks: `refs`, measurePair; one circle: two refs to it, `minmax: 'max'`; one arc: two `pt` refs at its ends). `{ kind: 'angrun', base, refs, cw?, cFix?, rad? }` -> measured `c, u, values (deg), value` (`Drawing.angRunMeasure`). `{ kind: 'pathlen', refs: [edge | { kind: 'rad', c, r, a0, a1 } | { kind: 'dia', c, r }], value, lead? }`. Both exploded in DXF (arc / lines / text), like ordinates.
- View: `{ id, name: 'Drawing View1', orient: 'Front', x, y, display: 'hlv' | 'hlr' | …, scale: null | [1, 2], parent, align, role, dims: [], kind?: 'section' | 'detail' | 'flat' | 'aux' | 'projected' …, label?, tangent?, showLabel? }`. `showLabel` (rfCQ) is stored only when it differs from the kind's default: read it with `Drawing.viewLabelShown(v)` (section / detail / aux on, the rest off), set it with `Drawing.setViewLabel(doc, id, on | null)` or `showLabel` in any `add…View` opts.
- Detail: `view.detail = { c, r }` (circle) | `{ shape: 'profile', a, b, c, r }` (rectangle, two corner clicks) | `{ shape: 'profile', a, b, c, r, pts: [[u, v] …] }` (rfCQ: a sketched polygon / spline, parent frame, counter-clockwise; `a` / `b` its box) + `style`, `outline: 'full' | 'jagged'`. Every profile path goes through `_.profilePts(dt)`; the content is cropped to the box (`detailProfileContent`) then `clipProjectionPoly`; hatching is clipped on the sheet (`_.clipLayerToPoly`, render).
- rfCU: cosmetic thread `{ type: 'cosmeticThread', c, r, size: '#10-32 UNF', end: 'through' | 'blind', depth?, callout?: false, lead?, text?, external? }` (sizes `HoleWizard.ANSI_THREADS`; size 'auto': `Drawing.threadForDia` by tap drill, by major diameter when external; the UI sets external when `holeInfo` says the picked circle is not a hole); `{ type: 'dowelPin', c, r }`; symbols `{ type: 'datumTarget', datum, num, area: 'point' | 'circle' | 'rect', aw, ah, size?, p, leader }`, `{ type: 'leader', p, jogs: [[x, y]], leader (tip), end: 'arrow' | 'dot' | 'none', note? }` (sheet symbol entry carries `pts`, the polyline, for hit testing); notes `border` (`NOTE_BORDERS`), `list` ('number' | 'bullet', laid out by `_.noteLayout`).
- Revision Table: `doc.revisions = { rows: [{ id, zone, rev, description, date, approved }], anchor, nextRow }` is a per-sheet key (`SHEET_KEYS`, rfCQ); `revTables(doc)` (active sheet first, then the others, through `doc._sheetBase` on a `sheetDoc` copy) feeds `latestRev` / `revRow`, so the title block REV is the drawing's.
- `compute(...)` -> `{ size: [W, H], units, prims, views: [{ view, proj, box, section?, hatches? }], dims, pending? }`; prims `{ k: 'line', a, b, layer, style }`, `circle { c, r }`, `arc { c, r, a0, a1 }`, `ellipse`, `text { p, h, text, anchor, rot }`, `fill { pts }`; styles `visible | hidden | thin | thick | bendup | benddown`. Paper units (model units), origin lower-left, y up.
- DXF layers: one per view (`FRONT`, `TOP`, `SECTION_A`, `DETAIL_B`, `FLAT_PATTERN` …) + `SHEET`, `DIMENSIONS`, `ANNOTATIONS`, `NOTES`, `BEND_UP`, `BEND_DOWN`, `BEND_NOTES`, `BOM`, `BALLOONS`, `TABLES`; `$INSUNITS` 1 in / 4 mm; R2000 writes DIMENSION entities with a DIMSTYLE, R12 explodes them; `%%c %%p %%d`.

## Traps
- Reattach (every render, `reattachUserDim`): edges follow by geometry only — the projection lines (`pr.all`: `[u0, v0, u1, v1, body]`) carry no edge or face ids. Generic `reattachDim` matches a collinear or parallel edge, so an edge that turns is lost; angle-type dimensions (Smart `angle`, `angrun`) go through `ctReattachLines` (lane CT2: collinear first, else the edge that keeps one old end, nearest the old direction, not along a sibling line, else parallel). A new dimension that measures between turning edges should use it too; (rfDN) a moved shared vertex is followed too (see below).
- Function names inside one engine IIFE collide silently: the later `function x` wins for the whole file (drawing-annotations.js already has `lineMeet`, `unit`, `fmtAngle`, …). grep the file before naming a helper; lane CT prefixes its own `ct`.
- Smart Dimension's state is `D.tool === 'dim'` plus `D.dimLock` ('h' | 'v' | null: Horizontal / Vertical Dimension); every place that ends the tool clears it.
- A new engine file goes in five places: index.html, tests/kernel-tests.html (headless/load.js reads that list), drawing-worker.js `importScripts`, CLAUDE.md publish list, and the lane table.
