# Transform tab, Levels and View tab — agent map
Read this first; find line numbers with `grep -n <name> anvil/docs/INDEX.md`. Update this card at the end of any lane that touched this area (add what you had to dig for; fix what is wrong).

## Files — one line each: what the file owns
- `ui-transform.js` — Mastercam Transform engine on sketch geometry: `UI.transformEntities` (2D affine move / copies / Join, every entity type), `UI.transformPreview`, `UI.transformAffine` (translate, rotate, scale, mirror, mul, apply, power, classify), the shared `UI.transformPM(def)`, `UI.transformMemory` (last-used values), the magenta preview tint, Position commands (Dynamic gnomon, Translate, Rotate, Mirror, Move to Origin), ribbon group captions (`UI.transformCaptions`, any tab whose items carry `group`). Loads last of the three.
- `ui-transform-3d.js` — Translate to Plane, Project, Roll / Unroll (Position) and Stretch, Scale (Size); its own plane-to-plane affine map (`frameMap`, `mapEntity`, `ellipseImage`); hooks on `UI.transform3D`.
- `ui-transform-layout.js` — Offset ▸ Entity, Offset ▸ Chains (Mastercam chaining), Layout ▸ Rectangular Array, Distribute; hooks on `UI.transformLayout`.
- `ui-nesting.js` — Transform ▸ Geometry Nesting PM (parts list, sheet, parameters, results, live re-nest, graphics-area overlay, Save DXF, ✓ makes a "Nest" document).
- `nest.js` — `Nest` (no DOM): true-shape raster bottom-left nesting, exact loops of lines / arcs, `Nest.check`, sheet entities / DXF. API is documented in its header.
- `ui-levels.js` — Levels Manager (Mastercam): part-wide numbered levels over the sketch layers (`model.levels`, `model.mainLevel`), the FeatureManager-pane tab, the status-bar level chip / popup, `UI.levels` API; wraps `UI.rebuild`, `UI.loadModel`, `UI.updateSketches`, `UI.refreshStatus` to sync.
- `ui-panels.js` (shared with the commands lane) — the `Transform:` ribbon array (`t(name, id, label, group, help)` → `UI['cmdT' + name]`), `viewTab(asm)` (the View tab), the View menu, the heads-up toolbar (`refreshHud`, `UI.HUD_ORDER`), `syncViewTab`.
- `ui-core.js` (shared) — the camera and view functions the View tab calls: `UI.setView`, `viewNormalTo`, `zoomToFit`, `zoomToArea`, `previousView` / `pushViewHistory`, `setBackground`, `setViewportTheme`, `updateTemp` (temp group of previews).
- `sketch-solver.js` (read for maths) — `SketchSolver.transformEntities`, `stretchEntities`, `contourOffset`, `offsetEntity`, `linearPattern`; used by the layout / 3d files.

- `evaluate.js` / `ui-evaluate.js` (Evaluate tab) — Thickness Analysis (lane rfGU): `Evaluate.thickness(body | [bodies], { target, treatCorners, resolution | samples, bins })` -> `{ min, max, mean, area, wallArea, cornerArea, histogram, below, above, samples, field }`; `Evaluate.thicknessStats(field, opts)` recomputes without casting. A sample's value is the thinnest of the inward ray and square-ended in-plane chords (the chords make rims read the wall); cylinders and spheres are measured on the true surface. Corner samples (over 1.25 × the surface's median, within that median of its edge) leave the statistics, or are 0 with `treatCorners`. Cones and tori are measured on the facets. UI: `UI.cmdThickness`, `UI.evaluate.thickness()`, `thicknessValues()`, `thicknessCalculate()`, `analysisGroup()`, `anvil.thickness(opts)`; the overlay is its own triangles (`userData.ownTriangles`), one colour per sample cell. Parameters change only on Calculate (the PM says so). Groups `rfGU` (kernel, smoke).

## How things are done here
- **A 2D Transform command**: `UI.transformPM(def)` (imitate `cmdTTranslate`). `def`: `name` (memory key), `title`, `icon`, `ops` (`OPS3` Move / Copy / Join, `OPS2`), `spacing`, `message`, `ready` (status prompt once entities are in), `values`, `points: { key: { key, prompt, next, live } }` + `pointField(key, box, label)` fields, `firstBox(v)`, `groups()` (PM groups as openPM), `onChange(key, ctx)` (**ctx, not values**: `ctx.v`, `ctx.f`, `ctx.setBox`), `needs(v)` → message while not ready, `step(v, t)` → affine for copy t (or `xfs`), `excluded(v)`, `forget`, `allWhenEmpty`, `onOpen`, `onApplied`, `onClose`, `afterPoint`. It handles the entities box, Move / Copy / Join, copies, live preview, ✓ and ✓+.
- **3D / layout commands** build their own `UI.openPM` spec (imitate `UI.cmdTScale` or `UI.cmdTOffsetEntity`): `transform: '<name>'` (turns on the magenta preview tint and tells tests it is a Transform PM), `command: cmd` (becomes `App.command`: `onSketchPoint(raw, mx, my)`, `onSketchMove`, `onSketchDrag`, `ownHover`), `keepSelection: true`, `extraActions: okPlus(apply, after)` (Mastercam ✓+, title "OK and keep open (✓+) …", icon `okPlus`), `recall(name, v, keys)` on open and `keep(name, v, keys)` on apply (`UI.transformMemory`; picked points / entities are never remembered).
- **Selection in Transform**: each file has its own `selIdx(f)` (lane BY): a selected end / corner / centre sketch point counts as its line / arc / circle and the selection becomes that entity. Keep the three copies in step.
- **One undo step**: ui-transform-layout.js `step(fn)` (fn → `{ ok, added, error }`; failure restores), ui-transform-3d.js `oneStep(fn)` (may touch several sketches; `restoreModel`). Levels: `begin()` = `UI.pushUndo()` (+ `sketchDirty` in a sketch). `UI.transformEntities(..., { undo: true })` pushes its own step.
- **After ✓**: the result stays selected and the result line wins over the selection's own status (`finish` / `done`); ✗ → `cancelled(title)` writes "<Title> cancelled." again after the close.
- **Previews**: set `App.tempEntities` and `UI.updateTemp()`; the tint wrapper in ui-transform.js recolours `UI.groups.temp` while `spec.transform` is set (`UI.transformPreviewColor()`: #b0279e light, #e879dc dark). Sketch tools keep their own colour.
- **Exact numbers**: `cosd` / `sind` are exact at quarter turns and `tidy` / `td` snap float noise (an array at 90° once gave 0.5000000000000001 in the DXF).
- **Two-Enter rule** applies to every Transform PM and the nesting PM (`UI.pmEnter`): first Enter commits the typed value ("press Enter again"), second is ✓. In Nesting the first Enter nests, only ✓ (or the second Enter) makes the Nest document. Quantity boxes are text boxes with a 350 ms re-nest debounce.
- **Levels**: every manager operation goes through `run(op, …)` (sync, op, sync, redraw) and is one undo step via `begin()`; making a level main is a setting, not a step. An entity on level 1 has no `layer`; any other level's entities carry `layer` = the level's key (its name, else its number as a string).
- **View tab item**: `{ id, label, key, group, help, run, active() }`; `stack` / `grid` / `fly` group buttons; captions come from `group` (laid out by `UI.transformCaptions` via a MutationObserver on `#ribbon-buttons`). Pressed state is `active()`; call `syncViewTab()` when a menu / HUD / F-key changes the same state.
- **Status / toast text**: prompts on the status bar ("Translate: type Delta X / Y (fractions like 1/2 work), or Polar, or pick From / To points; Enter (✓) moves, ✓+ keeps going."), results ("Offset: 1 copy at .250 in."), "Open a sketch: Transform acts on sketch geometry" as a toast when no sketch is open (`UI.transformSketch()`).

## Data shapes
- Affine in `UI.transformEntities`: `[a, b, c, d, e, f]` SVG order (x' = a x + c y + e, y' = b x + d y + f) or a list (one per copy); opts `copy`, `count`, `join`, `mirrorText`, `undo`, `select`; returns `{ ok, error, entities | added, joins, dropped, message }`. ui-transform-3d.js uses `{ a, b, c, d, tx, ty }` (`aff`) — a different order.
- Memory: `localStorage['anvil.transform']` = `{ <def.name>: { op, count, dx, … } }`; `UI.transformMemory.reset()` in tests.
- Nest part: `{ name, loops: [outer, holes…], qty, priority }`, loop `{ circle: { c, r } } | { segs: [{ t: 'line', a, b } | { t: 'arc', a, b, c, r, ccw, sweep }] }`; opts `{ width, height, spacing, margin, rotation, mirror, holes, maxSheets, corner: 'bl'|'br'|'tl'|'tr', direction: 'x'|'y', cell, tol }`; result `{ placements: [{ part, sheet, x, y, angle, mirror }], sheets: [{ utilization }], unplaced, placed, total }`.
- Levels: `model.levels = [{ number, name, color, hidden, noProfile, lineType, aci, set }]`, `model.mainLevel`; each sketch keeps `layers: [{ name: key, color, hidden, noProfile, lineType, aci }]`.
```js
UI.transformEntities(f, [0, 1], UI.transformAffine.translate(1.5, 0), { copy: true, count: 3 });
// translate(dx, dy) = [1, 0, 0, 1, dx, dy]; -> { ok, added: [new indices], joins, message }
Nest.run([{ name: 'Blank', loops: [{ segs: [...] }], qty: 21 }], { width: 96, height: 48, spacing: 0.25, margin: 0.5, rotation: 90 });
UI.levels.op('create', 10, { name: 'ETCH', color: '#00c000' });   // -> { ok, number }; each op's arguments: comment above it in Ops (ui-levels.js)
App.view = { style: 'shadedEdges', bg: 'gradient', showPlanes, showOrigin, showSketches, showGrid, sketchRegions, showDims, showEndpoints, snapModel, section };
```

## Traps
- Load order is ui-transform-layout.js → ui-transform-3d.js → ui-transform.js → ui-nesting.js: the first two read `UI.transformMemory` lazily (it does not exist when they load).
- `transformPM`'s `onChange(key, ctx)` has the opposite argument order to `openPM`'s `onChange(values, key)`.
- Every Transform test step must start from `UI.transformMemory.reset()` (commands remember Move / Copy, counts, distances): rfBK's Scale and rfBJ's Mirror steps broke on remembered values.
- Ctrl+Z / Ctrl+Y / Undo button with a command PM open cancel the command first ("Translate cancelled."), a second Ctrl+Z undoes (`undoCommand` in ui-app.js); text typed in a PM box keeps Ctrl+Z for that text; selection-only PMs and the Line tool undo at once.
- Any typing counts as an entry for the two-Enter rule, even retyping the same value (typing "3" over 3 used to close Rect Array).
- Nesting state belongs to the document it was made in (File ▸ New starts an empty list); a re-render per keystroke once scrambled a typed `12` into `21`.
- Nesting gaps run slightly over the spacing (cell ≈ sheet / 2000); fine accuracy with 45° + mirror takes ~5 s. Translate to Plane / Project have no Join; an unrolled hole crossing the seam is not split; Roll has no 3D wrap; no Move / Copy Body.
- Group captions are laid out by a MutationObserver in ui-transform.js, not by the ribbon renderer: a ribbon change that adds / removes children can mis-place them (they skip when `children.length !== items.length`).
- The Levels Manager and level popup are white with dark text in both themes (own palette, `color-scheme: light`); 20 px rows, FeatureManager font (rfBT).
- Levels sync runs before every rebuild, load, sketch redraw and status refresh (wrappers): heavy work in `sync` slows everything.
- View tab: the Levels Manager button is removed for assemblies (`viewTab(true)`); F5 refreshes the ribbon so `filter` follows. Show Endpoints is `App.view.showEndpoints` (localStorage `anvil.showEndpoints`, default on).
- Graphics area is grey-black in every theme; previews must read on it (magenta for Transform, orange for sketch commands); HUD glyphs need `--icon-ink` light on it. CSS overlays take the `--ov-*` variables (see ui-core card; rfDA).
- Group captions (`captions()`): a group narrower than its name gets a caption as wide as the name (`capTextWidth`, canvas measure at the ribbon's font), centred and clamped between its neighbours; the View tab's Managers was cut to "Mana" (rfDA).
- The View Selector sits on the model, not the middle (lane DA); the heads-up View Orientation menu moves beside it. Space shows the cube alone (user 2026-11-04); a middle-button press (rotate / pan / zoom) leaves it up and it turns with the view. Drawn in ui-core.js drawViewSelector as a solid lit cube (front faces only, bevel-toned edge / corner regions).
- `r11/occtswap11` is a known timing flake in full headless runs (passes alone).
- Display style matters to selection (lane FD): with *Select hidden entities* off (default) a box / lasso in Shaded With Edges / Shaded takes only visible edges and vertices; HLR / HLV / Wireframe take hidden ones (ui-select.js `occlusionWanted`). A View tab change of `App.view.style` needs nothing else.
