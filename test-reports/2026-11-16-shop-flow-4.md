## Fixed (my files)

**B2 (ui-commands.js `insertSources` / `lastPartSource`).** Insert Component lists "BRK-B (last part)" first; it
inserted a copy (`source: { model }`) even when BRK-B had just been saved, so a later edit of BRK-B never reached the
assembly (SolidWorks always inserts the part file). When the last part is identical to a saved document it is now
offered as "BRK-B (last part, linked, saved in this browser)" with `source: { file: 'BRK-B' }`; an unsaved or since
edited last part stays a copy as before. Smoke rfNW job b change step fails without it.

**E1 (ui-commands.js `measGeom`).** Measure took a hole's rim as one straight tessellation chord (and a cylindrical
face as nothing). A rim edge or a cylinder face with an exact `cyl` record now reads as the circle / axis ("Circle
Ø0.5", centre, axis), so with a straight edge it gives "Center distance" (and with a face, the distance), as
SolidWorks' Measure does for a hole.

**F1 (ui-rebuild.js What's Wrong).** A row for a feature made from a sketch also has **Edit Sketch** (SolidWorks'
right-click on the feature). Edit opened Hole 1's Cut-Extrude PropertyManager, where a hole that fell off the part
cannot be moved.

## Handed on

**B1 (assembly.js `cylinderFromPatch` / `fitCylinder`, assemblies lane).** Any flat face of a sheet-metal part that
touches a bend (the bracket's bottom, the tray floor) is returned by `refFromPick` as `{ cylinder }`: the facet fit grows
from the flat patch into the bend facets and the flange and fits a "cylinder" with no residual check. The Mate PM then
offers Concentric. Repro: rfNW job b (any 16 ga L bracket in an assembly, Mate, click its bottom face and the floor of a
tray). Fix verified in this lane (temporary, not committed): in `fitCylinder`, after the solve, refuse a fit whose
patches are not tangent to it:
`var bad = 0; region.forEach(function (q) { var e = Math.abs(dot(q.normal, e1) * sol[0] + dot(q.normal, e2) * sol[1] + sol[2] - q.w); if (e > bad) bad = e; }); if (bad > 1e-3 * Math.max(1e-3, Math.abs(sol[2]))) return null;`
With it job b mates every face by clicks (Coincident face / face, the brackets land at y = T), and the assembly kernel
groups (advanced-mates, distance-angle-mates, sub-assemblies, r4-asm4, rfGV, rfGW, rfIV, rfJA, rfKA, rfKF, rfLP) pass 134 / 134. rfNW job b falls back to `anvil.mate` with the clicked refs while B1 is open (noted in the
step); remove that branch once fixed.

**D1 (ui-panels.js Tools ▸ Units, with a kernel helper).** On a part with features the menu only sets `model.units`: a
100 mm bracket becomes 100 in (2 in thick), its flat 100 x 86.52 in. SolidWorks converts (the geometry stays). Proposal:
`Kernel.convertUnits(model, to)` scaling every length (sketch entities and dimensions, feature length fields by type,
`sheet` thickness / radius / allowance / deduction, hole wizard depths, plane offsets, equations' values marked as
lengths), one undo step; or keep the model's own units and make the document units display only. Until then rfNW job d
checks the inch DXF against the size the part shows.

**D2 (drawing lane).** No dual dimensions anywhere (Document Properties). SolidWorks: Dual dimensions display, the
secondary unit in brackets. Proposal: a drawing option `dual: 'mm' | 'in' | null` and `[25.40]` after (or under) every
dimension and callout value.

**F2 (kernel message, cut rebuild).** A cut whose profile no longer lies over the part says "Reverse its direction or
change its end condition", which cannot help. Proposal: when the profile region does not overlap the body's projection
on the sketch plane, "Hole 1's sketch (Sketch2) lies outside the part: Edit Sketch to move it."

**C1 (low, holewizard.js `HW.callout`).** The Hole Wizard PM shows "Ø.201 THRU" where the drawing (and SolidWorks)
write THRU ALL for a Through All hole.

**B3 (low, drawing PDF name).** Save Drawing as PDF names the file `Draw1_Assem1.pdf` although the assembly is saved
as TRAY-ASM; SolidWorks names it after the document file. Proposal: use `App.fileName` when set.

**A1 (note, kernel-equations.js).** The Design Table cannot drive a sketch dimension ("drive the sketch with a global
variable"), so a bracket family cannot change the base flange's size; and it offers D1 / D2@Base-Flange1, the sheet
thickness as an extrude depth, which would put the base out of step with `model.sheet`. Proposal: leave sheet-metal
base flanges out of the column list (or map D1 to the sheet thickness).

**C2 (note, ui-holewizard.js).** Hole Wizard positions are where the clicks land (2.0032, 1.9967 …); the PM has no X / Y
to type. SolidWorks dimensions them in the positions sketch, which Anvil allows (Edit Sketch on it).
