## Fixed

1. **A Cross-Break broke when the gauge changed** (`kernel-sheetmetal.js` SM_PICKS, crossBreakLayout).
   - The Cross-Break's face pick was a bare point and had no persistent reference.
   - 18 ga to 16 ga in the Sheet-Metal PM moves the top face .012 up. That left the point inside the sheet, and the feature failed with "no planar sheet face at (12, 0.0478, 18)".
   - Fix: `crossBreak: [['face', 'face', true]]` in SM_PICKS, so the pick follows the face like the other sheet-metal picks. The layout's `at` is now projected onto the face it found.
   - After the fix: every feature rebuilds, the point moves to y .0598 and the CROSS BREAK note stays in the DXF. Tested in kernel rfQI 2 and in smoke rfQI 1, which drives the gauge drop-down in the Sheet-Metal PM.
2. **A Jog or Sketched Bend across a face with return flanges built an open part with no error** (sketchedBendLayout).
   - Example: a jog across the door after its four flanges gave 30 open edges.
   - It is now refused: "Jog: line 1 runs into a flange or wall at its end: the bend would cut it in two. Bend lines must end on free edges of a flat face; add the jog before the flanges on those edges."
   - How it is detected: metal standing off the face at either end of the bend strip.
   - Tested in kernel rfQI 4 and smoke rfQI 2. SolidWorks' exact message is not checked.
3. **A Rib used as a gusset put phantom holes in the flat** (`hasWelds` / `weldFreeFlat`).
   - An 11 ga L with two Ribs gave 5 loops, with 0.356 in² missing where the Ribs met the faces.
   - Ribs are now left out of the flat, the same way Welded Corners are. The flat shows the warning "Rib1, Rib2: a Rib is not sheet metal (a welded-in gusset plate) … Sheet Metal Gusset is not available."
   - The warning appears in Flat-Pattern1 ▸ Flat Pattern… (smoke rfQI 3).

## Handed on

**H1 (kernel-sheetmetal.js `loftedBendLayout`): the Lofted-Bend strip does not match the hand layout at a mid-side seam.**
- The least-total-diagonal DP fans the seam point (in the middle of the front side) to half the corner's quarter arc. That puts two bend lines on what is one flat triangle in a hand layout (B −89.1° … −44.6° from A(0, −3)).
- Proposed fix (measured): minimise Σ diagonal length × the angle between its two facets (+1e-6 × length). The flat then equals the hand layout to 1e-14 at n = 4 and n = 8, and rfJJ / rfKG / rfKP / rfKR still pass.
- It changes two tests I may not edit, and the fix was taken out again:
  - rfJZ "one face per facet": the two half triangles of the seam side now lie in one plane (3e-8), and STEP writes 83 faces for 84 mesh faces. The STEP round trip is still exact (3e-9) and closed.
  - rfMV shop drawing e: "bendNote over bendNote", because the seam corner now fans its full quarter (drawing lane: note placement).
- Patch (replace the DP block after `B = B.slice().reverse();`):

```js
    var m = A.length - 1, n = B.length - 1, INF = Infinity, cost = [], from = [];
    function facetN(i2, j2, h2) {
      var p = h2 === 1 ? [A[i2 - 1], A[i2], B[j2]] : [A[i2], B[j2], B[j2 - 1]], c = cross(sub(p[1], p[0]), sub(p[2], p[0])), l = len(c);
      return l > 1e-12 ? scale(c, 1 / l) : null;
    }
    function bendCost(i2, j2, hPrev, hNext) {
      var a = facetN(i2, j2, hPrev), b = facetN(hNext === 1 ? i2 + 1 : i2, hNext === 2 ? j2 + 1 : j2, hNext);
      var ang = a && b ? Math.acos(Math.max(-1, Math.min(1, dot(a, b)))) : 0;
      return d(A[i2], B[j2]) * (ang + 1e-6);
    }
    for (var i = 0; i <= m; i++) { cost.push([]); from.push([]); for (var j = 0; j <= n; j++) { cost[i].push([INF, INF, INF]); from[i].push([0, 0, 0]); } }
    cost[0][0][0] = 0;
    for (i = 0; i <= m; i++) for (j = 0; j <= n; j++) for (var hp = 0; hp < 3; hp++) {
      var c0 = cost[i][j][hp];
      if (c0 === INF) continue;
      [1, 2].forEach(function (hn) {
        var i2 = hn === 1 ? i + 1 : i, j2 = hn === 2 ? j + 1 : j;
        if (i2 > m || j2 > n) return;
        var c1 = c0 + (hp ? bendCost(i, j, hp, hn) : 0);
        if (c1 < cost[i2][j2][hn] - 1e-12) { cost[i2][j2][hn] = c1; from[i2][j2][hn] = hp; }
      });
    }
    var steps = [], h = cost[m][n][1] <= cost[m][n][2] ? 1 : 2;
    for (i = m, j = n; i > 0 || j > 0;) { var hb = from[i][j][h]; steps.push(h); if (h === 1) i--; else j--; h = hb; }
    steps.reverse();
```

Then rfJZ's assertion should count planes, not facets, and rfMV needs the drawing lane's note spacing at a 5-line corner fan. kernel rfQI job 3 prints both areas; with the patch its numbers become the hand layout's.
