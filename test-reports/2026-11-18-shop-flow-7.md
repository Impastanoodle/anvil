## Fixed (my files)

**A1 (ui-commands.js `editGaugeTable`, `gridDialog`): the shop's bend deduction per gauge.** A gauge pick fills T, R and
K from the row, so a typed Bend Deduction .135 became the shipped table's example K .5 at the next gauge pick (the
blank changed with no word). The kernel already read `bendDeduction` on a gauge row (`Kernel.gaugeRow`), but *Edit gauge
table…* had no column for it. It now has an optional *Bend deduction* column (blank = the row's K-factor; pasted rows
may leave it off); a row with a value gives Bend Deduction for that gauge. Smoke: fix A1 (14 ga .135, 11 ga .21, the
11 ga blank 9 + 4 T − 4 x .21). Before: the column was not there (the step fails at "a Bend deduction column").

**A2 (ui-panels.js, kernel-equations.js `configureDimension`, 4 lines in ui-select.js): This configuration in the Modify
box.** In a part with two or more configurations the Modify box of a model dimension (Edge-Flange length, extrude
depth, fillet radius, pattern spacing, a sketch dimension shown on the model) has a *This configuration (BR-B)* /
*All configurations* choice under the value (a button that toggles, so the value keeps the focus; SolidWorks has a
list). This configuration links the dimension to a variable as a Design Table column does (D1_Edge_Flange1, the same
code path: `Kernel.applyDesignTable`) and sets it in the active configuration only; All configurations sets the
variable and drops every configuration's override. Default: This configuration (SolidWorks' default not checked).
ui-select.js (no lane this round): `openEdit` calls `UI.configDimBox`, `closeEdit` calls `UI.configDimApply` first,
`extrudeHandle` / `otherFeatureHandles` take a configured value from `UI.configDimValue`.

**A3 (ui-commands.js `instant3DFeatureHandles`): a configured Edge-Flange length keeps its arrow.** The flange length
handle read `+f.length`, NaN for '=D1_Edge_Flange1', so the dimension vanished from the model once configured.

**A4 (ui-panels.js `showDesignTable`, `closeModal`, the last block; style.css): the Design Table leaves the model reachable.** The dialog is `#modal.dt-pick`: no backdrop, the card at the top right, clicks outside it reach the viewport. A double click on a face shows its feature's dimensions (`UI.showFeatureDims`); a double click on a dimension (the press opens its Modify box, which is closed again) adds its column (`UI.designTableState.addColumn('D1@Edge-Flange1')`, the Add Column list's own path; a column already there is not added twice). Smoke: fix A4. Before: `elementFromPoint` under the dialog was `#modal` (the step fails at 'the model is reachable').

## Handed on (other lanes' files)

**H1 (kernel-sheetmetal.js `flangeLayout`, ui-commands.js Edge-Flange PM; lane flangeprofile): a length per edge.**
SolidWorks makes one profile sketch per edge of an Edge-Flange, so each edge's length can differ in one feature (not
checked in SolidWorks 2024 how it is offered in the PM). Anvil: one `length`. Proposed: `f.lengths: { <edge index>: L }`
read in flangeLayout where `L = +f.length` (L287) per record, the PM's on-screen length arrow per edge
(`UI.flangeLengthHandles(recs, length, near)` already picks the record nearest the face) writing `lengths[i]`.

**H2 (kernel-sheetmetal.js, ui-commands.js `cmdBreakCorner`; sheet-metal lane): Corner-Trim in the flat.** Flattened,
SolidWorks' Break-Corner/Corner-Trim becomes Corner-Trim (Relief Options at the bend corners: Circular / Square / Bend
Waist, centred on the bend lines, and Break Corner options), a feature under Flat-Pattern that the folded part does not
show. Anvil opens Break Corner in both states. Repro: job 2, Flatten, Corners flyout.

## Notes (not changed)

**N1.** A bend beyond 90° writes `bd` from the outside setback R + T (Anvil's Tangent convention, README *Bend allowance*):
the 135° bend's note reads bd .0399; the closed form with tan(A/2) (.5058) is the virtual-sharp one. The blank is the
same either way (it is the developed geometry); only what "BD" means on such a bend differs: worth a word with the user.

**N2.** A drag of a configured dimension's arrow (not a typed value) still writes a plain number into the feature, which
unlinks it from its variable (ui-select.js drag path; the typed path goes through A2).

**N3.** Welded Corner on Material Inside flanges: the wall ends stand .0071 off the next wall's inside face, so the end
face cannot be clicked in any orthographic view. SolidWorks offers Select Other; worth a check that Anvil's Select Other
reaches it.

**N4.** No nesting / sheet-yield command (SolidWorks has none built in either for parts; Costing quotes from the blank).
