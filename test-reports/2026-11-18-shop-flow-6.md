## Fixed (my files)

**A1 (holewizard.js, ui-holewizard.js): Hole Wizard Up To Next.** The End condition had Blind and Through All only, so
a hole in one wall of a chassis or box went through the opposite wall too (SolidWorks' Through All does the same; a
shop picks Up To Next). `end: 'next'`: `nextDepth` casts rays along the axis and round the drill's rim (.98 R) against
the bodies before the hole; the depth is the farthest first exit, carried halfway into the gap to the next material
(as far again with nothing beyond), so the cut ends in air. Callout "Ø.201 THRU" (SolidWorks writes plain THRU for an
end other than Through All); a tap's thread THRU; `threads()` depth null; the script writes `end: "next"`.
`HoleWizard.nextDepth` is exported for OpenCascade (H2). Smoke: job 1 hardware.

**A2 (ui-app.js `libraryFeature`): a Design Library feature on sheet metal is Link to thickness.** It was a Through All
cut: the PEM hole on the right wall also cut the left wall. SolidWorks' sheet-metal library features cut the sheet they
are dropped on. On a sheet part the cut is now blind T with `linkT` (follows the gauge); the status says "through the
sheet". Smoke: job 1 hardware.

**A3 (ui-commands.js `dxfCfgTag`): the flat DXF of a configuration is named for it.** Every size of a Design Table
family saved as LBRK-14_flat.dxf (the browser then numbers them). With two or more configurations the default name
carries the active one: LBRK-14_LB-4_flat.dxf. Smoke: job 2.

**A4 (ui-commands.js `selectedSolidIds`, `commitSources`, Mirror / Linear / Circular Pattern PMs).** Features picked
before the command (Ctrl+click in the FeatureManager) all go in SolidWorks' Features to Mirror / Pattern; Anvil took the
first and dropped the rest silently (a mirrored or patterned tab without its hem). The kernel's mirror / pattern take one
feature, so the PM lists the others ("Also: Hem1 (each mirrored as its own feature)") and ✓ makes one feature per
source, in FeatureManager order, one undo step (Mirror1 of Edge-Flange1, Mirror2 of Hem1 lands on the mirrored flange).
Smoke: job 3.

**A5 (ui-commands.js `sketchThen`): ✓+ after a sketch on a picked face.** A face clicked, Extruded Cut, the sketch, Exit
Sketch: the Cut-Extrude PM came back without ✓+ (the command had already returned when the PM opened; `pendingAfterSketch`
ran it outside `runAgainable`). It now runs through `runAgainable`, so ✓+ makes the cut and opens the next Cut-Extrude.
Smoke: this round's additions.

## Handed on (other lanes' files)

**H1 (drawing-annotations.js; lane drawgaps2): Up To Next in callouts and the Hole Table.** Repro: job 1 (a Hole Wizard
#10 with `end: "next"`, Make Drawing, Hole Table): the size reads "Ø .201 ↧ 0". Fix: in `wizardLines` (L2084) add
`next = f.end === 'next'` and write `thru ? ' THRU ALL' : next ? ' THRU' : ' ↧ ' + …` on the drill line (L2087) and the
thread line (L2088); L2032 `thruAll: f.end === 'through'` stays, add `thru: f.end === 'next'` if the row wants plain THRU;
L2036 and L2242 `thru = f.end === 'through' || f.end === 'next'`.

**H2 (occt-kernel.js `holeTool` L847; lane smmirror): Up To Next on OpenCascade.** It cuts `f.depth` (0: an error) for
`end: 'next'`. Fix: for 'next', triangulate the current bodies into convex polygons `{ plane: { normal, w }, vertices:
[{ pos }] }` and take `L = HoleWizard.nextDepth(f, s, plane, q, { bodies: [{ polygons }] })` per position (or ray-cast
the shapes with BRepIntCurveSurface_Inter: the farthest first exit of the axis and rim lines, halfway into the gap).

**H3 (drawing-ui.js `onDblClick` L1309, drawing-sheet.js; lane drawgaps2): edit a BOM cell in place.** Repro: job 4's
drawing, double-click the END-A cell: the Bill of Materials PM opens. SolidWorks edits the cell text in place (for a
cell linked to a property it asks whether to keep the link, editing the part's property, or break it). Fix: find the
cell under the pointer (`Drawing._.bomCell`), open the inline editor there; store an override per row key and column
(`doc.bomRows[key].cells[col]`) that `bomCell` returns before the property; for PART NUMBER / DESCRIPTION offer
"edit the part's property" (File Properties of that part) like SolidWorks' link prompt.

**H4 (drawing-ui-tools.js `safeName`, L1006; lane drawgaps2): Save Drawing as PDF of a configuration.** Every size of
job 2 saved as Draw1_LBRK-14.pdf. Fix: add the configuration the views show when the part has two or more
(Draw1_LBRK-14_LB-4.pdf), as A3 does for the DXF; worth also storing the configuration on each view (SolidWorks'
Reference configuration) so a drawing keeps showing LB-6 after another one is made active.

**H5 (kernel-sheetmetal.js; sheet-metal lanes): Tab and Slot, and partial-width Edge-Flanges.** SolidWorks 2024's Sheet
Metal tab has Tab and Slot (tabs on one body's edge, matching slots cut in the face it meets); Anvil has none. Also an
Edge-Flange always runs the whole edge (no Edit Flange Profile / offsets), so tabs along one edge need a base outline with
tabs (as job 3 does). Both are kernel work.

**H6 (library.js `addFeature`; no lane owns it this round).** The script path `AnvilLibrary.addFeature` still writes a

cut.depth = T; cut.linkT = true; }`).

## Notes (not changed)

**N1.** A BOM row whose part has no Description property shows its size (".750 x 4.000 x 6.120"); SolidWorks shows the
property, blank when there is none. Worth asking the user which a shop prefers.

**N2.** With Document Properties ▸ Dual dimensions display on, the Hole Table's X / Y LOC stay single (5.867): check
SolidWorks 2024's hole table (Document Properties ▸ Tables ▸ Hole has its own dual setting, I believe).

**N3.** Insert Bends offers K .5 on an imported part (SolidWorks' default too); the shop's .44 has to be typed each time.

**N4.** The job 4 box clashes are the design's: an end panel's flange with R .06 inside cannot wrap the square end of a
wall; the parts need corner notches or reliefs. Interference Detection found every one of them.
