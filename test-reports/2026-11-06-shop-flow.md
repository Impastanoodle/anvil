# Shop flow audit, 2026-11-06 (lane shopflow, group rfJQ)

Three shop jobs run start to finish. The app was driven in headless Chrome (`tests/smoke/rfJQ.js`, real mouse
events on the Edge-Flange edge pick, PM fields and ✓, Annotation ▸ Punch Table, and File ▸ Save Drawing as DXF / PDF
from the menu bar). The outputs were checked with the engine under Node (`tests/kernel/rfJQ.js`, DxfCheck):

| Job | Part | Blank (hand) | Blank (Anvil) |
|---|---|---|---|
| a | 16 ga (.0598) CRS L-bracket 4 x 3 base + 2 flange, R .060, K .44, Material Inside, 2 x Ø.281, a .281 slot | 4 x (5 − BD .10402) = 4 x 4.8960 | 4 x 4.8960 |
| b | 14 ga (.0747) open box 10 x 6 x 2, R .075, K .44, rect auto relief, hem .375 on the front, 2 circular Corner Reliefs | 10 + 2 (2 − BD .12996) = 13.7401 wide | 13.7401 x 10.1757 |
| c | 18 ga (.0478) panel 12 x 8, four louvers in a row | 12 x 8 | 12 x 8 |

What passed: laser DXF R12 and R2000 read back clean (closed loops, inch header, blank at 0,0, holes, the slot,
louver slits on HOLES, louver outlines on FORM, relief holes inside the outline). Bend Table BD values match the hand
values (.104, .130). Hole Table: 2 x Ø.281 THRU ALL. Punch Table: A1..A4 at 3 / 5 / 7 / 9, 4.000. The title block is
filled (TITLE, THICKNESS .0598, MATERIAL, MASS). No dimension, table or flat note lands in the title or tolerance
block, across another view, or past the border, on any of the three sheets. Drawing DXF reads back, and the PDF is
one page per sheet. There were no console errors. Every step ran under 3 s: the Edge-Flange ✓ about 0.1 s, the box
with Corner Relief about 0.6 s under Node, the whole UI job b + c step 1.8 s.

No finding below is a small clear bug in this lane's files, so this lane made no code fix. All are design decisions
or are in other lanes' code; they are left for the head.

## Findings, ranked by how much they would bite a shop

1. **Script `p.flange` default length is not SolidWorks' (medium).** Repro: `p.flange(2, [[2, .0598, 0]], { position: "inside" })`
   on a 4 x 3 base gives a flange 2.1198 tall (L + R + T: the legacy `lengthRef: 'wall'`), so the blank is 4 x 5.0158, not
   4 x 4.8960. Expected per SolidWorks: Edge Flange length is measured from the Outer Virtual Sharp by default. The
   Edge-Flange PM already defaults to `outer` (rfJQ smoke checks `lengthRef === 'outer'`). Only scripts and Claude's own
   parts hit it. Every script in this audit had to write `lengthRef: "outer"`. Changing the default would change old
   saved parts, so it is a head decision (kernel-sheetmetal.js `flangeLayout` / Builder `flange`).
2. **A 4-edge Edge Flange closes its corners itself, so Closed Corner then refuses (medium).** Repro: job b's four
   flanges in one feature (Material Inside). The front / back walls run the full 10 in and the side walls stop at their
   inside faces, which makes a butt-closed corner with no gap. `p.closedCorner([[0.0747, 1, 0.0374]])` then fails with
   "there is no flat face at (…) any more". Expected per SolidWorks: an Edge Flange on contiguous edges leaves a
   mitred corner with the miter gap, and Closed Corner then closes it (butt / overlap / underlap). The message should
   say the corner is already closed. This is kernel-sheetmetal.js `flangeLayout` and `closedCornerLayout`, other lanes'
   files. Check it against SolidWorks before changing anything.
3. **The flat view goes on at half the sheet scale (low).** Repro: job a, Standard 3 View at 1:1 on ANSI B, then
   `anvil.drawing.flatView()`. The flat lands at 1:2 with a "SCALE 1 : 2" label beside the views. Job b's flat goes to
   Sheet 2 (fit, rfIW). Expected per SolidWorks: the flat view takes the sheet scale and is placed where you click; a
   shop usually wants the blank at 1:1, or on its own sheet. Placement policy is a head decision (drawing-sheet.js
   `addFlatView` `fit`).
4. **The flat DXF header extents include the bend-note texts (low).** Repro: job a, DXF/DWG Output with Notes on: `$EXTMAX` is
   4 x 5.016 while the blank is 4 x 4.896. This is correct DXF (text counts toward extents), but a nesting import that
   sizes parts from the header would read the blank .12 in long. Untick *Notes* for a pure cut file. This lane made no
   change.
5. **Hole Table on a part with no holes (low).** Repro: job c, `anvil.drawing.holeTable(flatId, { all: true, origin })`
   inserts an empty table with a header only. A Punch Table on a flat with no forming tools does the same, and rfJG
   tests that on purpose. Whether to refuse with "no holes in this view" or keep the empty table is a head decision
   (drawing-annotations.js `addHoleTable`, the file the flat-view Autodimension lane has open now).
6. **Bend Table Inner Radius `0.060` next to BD `.104` (not a bug).** The two columns use different leading-zero rules. That is
   deliberate (rfGW: SolidWorks' bend-table template writes the radius that way). Noted only because a shop reviewer
   will ask.

## Not covered

Sketching the profiles with the mouse: the sketches came from scripts, and the PMs and menus were real clicks.
