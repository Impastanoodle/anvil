# Drawing fidelity audit — SolidWorks 2024 vs Anvil (b41274c), 2026-10-12

Lane: drawing fidelity checks (audit only, no app file edited; 30-minute time box). Every observation was made on
today's code (`b41274c`) served on port 8877 and driven in headless Chrome over the DevTools protocol with **trusted**
input (ribbon buttons and menus clicked, sheet clicks by paper coordinate through the SVG's screen CTM, Esc / ✓ / ✗),
the way a SolidWorks user drives it. The part was an **inch sheet-metal bracket** built with `anvil.run`: 16 ga
(.0598, R .0598, K .44) 6 × 4 Base Flange, two Ø.281 holes and one Ø.500 hole, an Edge Flange up (1.5) on the x = 0
edge and one down (1.0) on the far edge; then *File ▸ Make Drawing from Part* (Standard 3 View on ANSI B, 1:2 auto),
*Model View ▸ Flat pattern* placed at the right, *Model Items*, *Smart Dimension* on an edge and a hole, every
Annotation and View Layout button opened for its PropertyManager, a hole callout, the revision table, *Save as PDF /
DXF* and *File ▸ Save*. The driver and scenario (`drdrv/drv.js`, `s_draw.js`) live in the session scratchpad, not in
the repository. The scenario was run twice (`run1.txt`, `run2.txt`); only observations present in both are reported.
Half / aligned / offset sections, broken-view dimension mapping, multiple sheets and view-attached notes are being
added by other lanes this run and are not reported here.

## Findings

Severity: **blocker** (silently wrong geometry or data), **major** (a core SolidWorks workflow fails or behaves
differently), **minor** (a difference a SolidWorks user notices and works around), **cosmetic**.

## What matched SolidWorks

- **Make Drawing from Part**: the menu slot, the *View Layout* / *Annotation* / *Sketch* / *Markup* / *Sheet Format*
  tabs, Standard 3 View third-angle (Top above Front, Right to the right, Isometric in the free corner) on **ANSI B
  for an inch part**, `Draw1`, `Sheet1`, `Drawing View1…4`, auto centre marks on every hole and auto centerlines on
  the flanges seen from the side.
- **ANSI decimal-inch text**: three places, trailing zeros kept, no leading zero (`6.120`, `Ø.500`, `2X Ø.281`,
  `R.060`), unilateral `+.003/-.000`, `2X` on repeated hole sizes, `°` on angles; the general-tolerance block
  `DIMENSIONS ARE IN INCHES / .XX ±.01 / .XXX ±.005 / ANGLES ±1°`, `THIRD ANGLE`, `SHEET 1 OF 1`, mass in lb, UNITS `IN`.
- **Flat-pattern view** from *Model View* (Flat pattern first in the list on a sheet-metal part): the blank
  7.635 × 5.135 matches `Kernel.flatPattern` (BD .104 per 90° bend at K .44, 16 ga), bend lines with `UP 90° R.060` /
  `DOWN 90° R.060` upright beside them, the bend table with tags A / B and the per-bend deduction `.104`, holes as circles.
- **Annotation tab**: Smart Dimension with the Ordinate / Baseline / Chamfer flyout, Balloon / Auto Balloon / Stacked
  Balloon, Hole Callout, Note, Surface Finish / Datum Feature / Geometric Tolerance flyout, Revision Table, Center
  Mark (Single / Linear / Circular, extended lines), Centerline, all taking clicks until Esc; Ordinate asks Horizontal /
  Vertical then base + features; Break PM (vertical / horizontal, gap .4 in, Zig Zag / Straight) and Crop PM.
- **Revision Table** inserted top-right with REVISIONS / ZONE / REV / DESCRIPTION / DATE / APPROVED; **Sheet
  Properties** dialog with name, format (A / B / C / D and ISO), scale, projection and the title-block links.
- **Exports**: PDF is a true 17 × 11 in page (MediaBox 1224 × 792) with the sheet text; DXF R12 / R2000 choice in the
  dialog, `$INSUNITS` 1, one layer per view.
