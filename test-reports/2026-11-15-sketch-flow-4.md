# Sketch flow audit, round 4 (lane MW, 2026-11-15)

Eight shop flows the 2026-11-11 and 2026-11-15 tables did not cover, driven in headless Chrome with real mouse and key
events on **inch** parts, plus the neighbours of round 3's "click on a face selects the model face". Every flow ends
with dimension edits, Ctrl+Z back to the empty sketch, Ctrl+Y forward to the same sketch, and Exit / Edit Sketch to
the same sketch and status. Smoke group `rfMW` (one step per flow), kernel group `rfMW`.

**Inch parts.** There is no `UI.setUnits`: a document becomes inch by Tools ▸ *Units: inches (IPS)* (sets
`model.units` and rebuilds) or, for a new part, Tools ▸ *Default units for new documents ▸ Inches* (`UI.setDefaultUnits`,
read by `anvil.newPart`). The smoke page sets the default to mm, so rfKU's "inch" part was a mm part. rfKU's set-up
now sets the default to inches around `anvil.newPart()` (and puts it back) and asserts `UI.unitLabel() === 'in'`; its
assertions held unchanged in inches.
